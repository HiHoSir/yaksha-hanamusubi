# 制作手順と素材契約

## 1. イメージ図を設計する

採用済みの村用ピクセル画を視点・色・材質・ドット密度の参照にする。1990年代SFC和風RPGの、広い屋根面と浅い正面を持つ正投影トップビューとする。アイソメ軸・消失点・奥ほど小さくなる尺度を混ぜない。フィールドの記号的な集落タイルを村の建物素材に流用しない。

最初に地図セルと経路を決め、建物・井戸・橋・通路の寸法を図上へ割り当てる。端までぎっしり物を詰めず、村の周辺地形も含める。屋根裏や木冠の下を歩かせない一枚背景なら、その通行禁止を地形配置と明示セルで成立させる。必要地点へ到達できない細道を描画だけで「通路」と呼ばない。

生成画像の寸法や「32pxに見える」模様を信用しない。最終キャンバスを `列×32` × `行×32` に対応付け、マス目は別の検査オーバーレイで重ねる。画像の一括リサイズだけでは扉位置や道幅は揃わない。個別の位置・寸法を修正してから採用する。採用済み画像の構成を変更する際は、変更可能範囲を確認する。

## 2. 素材契約を短く記録する

必要フィールド：ID／用途（構想図・背景・チップ）／カテゴリ（地形・歩ける装飾・物体・建物）／参照と役割／表示W×Hセルと最終px／接地アンカー／整数占有列／入口と接近セル／描画レイヤーと遮蔽／透過／接続規則／保存先。

既存素材で役割が満たせるなら再利用する。祠・鐘撞堂・神社など別の役割は別IDとし、追加依頼で既存を勝手に改名・置換しない。左右の狛犬など差分が必要な対物は、向き・口・装飾を契約へ明記する。

## 3. チップの座標

接地最下段左端を `(x,y)` とする。テンプレートの相対セルは下段 `dy=0`、奥が負。可視画像下辺は `(y+1)*tileSize`、横方向は宣言幅の中央へ合わせる。PNG余白を切る場合は `sourceRect` または同等のオフセットを記録する。画像枠、可視形、接地、占有は別概念。

小型店舗の例（対象ごとに変更する）：

```js
const template = {
  id: 'small_medicine',
  displayCells: [3, 2],       // 96×64pxの絵
  sourceRect: [0, 0, 96, 64],
  occupiedTiles: [[0,-1], [1,-1], [2,-1], [0,0], [2,0]],
  entranceLocal: [1, 0],
  approachLocal: [1, 1],
  layer: 'object'
};
// アンカー(4,3)なら入口(5,3)、接近(5,4)。
// 配置データではoccupiedTilesを整数の地図セルへ展開する。
```

対称建物の1セル中央入口には3・5などの奇数幅を選ぶ。4セル幅の中央は境界になるため、入口を半セル座標へずらさない。4セルが必須なら2セル入口などの仕様を別に決める。

現行村素材の初期値：井戸・狛犬・樽など小物は1接地セル不可。木は1セル不可で表示2セルまでを目安とする。畑は1セル全面の土に3株×2列、通行可。小型建物3×2は上段3＋下段左右2セル不可、中央入口可。看板・落ち葉・踏み石は通行可、立て札は不可。これは初期値で、画像から自動計算しない。高低差を導入する場合は別途移動規則を設計する。

## 4. 一枚絵から切り出すとき

一枚背景へ焼かれた物体には、隠れた輪郭や床の情報がない。雑な矩形切抜きで草や隣の家具を抱え込ませない。独立チップ化は、清潔に抽出可能な可視部分を使うか、許可済みの生成・修復で欠けを補う。完全透過を求められたら真正RGBAにし、白・黒・市松模様を絵に残さない。床タイルは逆に全面不透明を基本とする。

原画は保持し、最終サイズは別名PNGへ保存する。原画が後で消えても再構築できる規格化sourceを残す。ハードなピクセル画ではalpha 0/255と少数色を確認するが、単純な減色で輪郭や表情が潰れていないか等倍で見る。周辺へ影や床パッチを増やさない。

## 5. プロンプトの組み方

契約を以下の順で一つの制約付き依頼にする。世界観の説明で寸法条件を埋めない。

1. 単独素材か背景全景かを明記する。
2. 参照画像ごとに「画風のみ」「外見」「配置」の役割を指定する。
3. 主体・識別に必要な特徴・視点・表示セル数・最終寸法・接地を指定する。
4. 透過／不透明、接続の有無、含めない地面・枠・ラベル・影を指定する。
5. 生成は原画段階とし、出力後の寸法・alpha・画風検査を予定する。

店の用途は原則看板差分で示し、茶店など採用済み専用外観は残す。壁付け看板は建物との重ね順も記録する。建物の中へ埋める絵なら、描いた順番次第で看板が消えないことを確認する。

## 6. 検査と納品

- 寸法、RGBA、実透明画素、不要余白、下辺接地、輪郭、32pxの実キャラとのドット密度を確認する。
- マス目・通行不可・入口・出現点を別表示し、全入口・接近セル・会話地点・出口へ4方向経路を通す。占有の範囲外・重複を検査する。
- 動的描画では後ろ／前／移動途中を確認し、物体接地下辺と補間中の可視足元で共通深度順を使う。全物体を機械的に3分割しない。
- 自動＋手動修正では素材判定→手動不可→手動可。完全手動では未指定を通行可とし画像初期判定を使わない。画像・占有元データは保持する。
- セーブ往復・旧データ・Undo・セルサイズ変更を対象に応じて検査する。32pxを基準とし、表示倍率や16〜64pxの編集セルを別の素材設計と混同しない。
- 合成背景PNGと地面のみPNGを区別する。木冠・屋根の動的遮蔽には地面＋JSON＋チップを渡す。グリッド・判定色・検査用キャラを完成背景へ焼き込まない。

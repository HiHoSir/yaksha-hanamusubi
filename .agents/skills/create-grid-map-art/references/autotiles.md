# オートタイルの制作と検査

生成するのは草・土・砂利・水・木材などの材質原画。接続マスクと共有辺はコードで構築する。生成された綺麗なシートを接続検査なしに採用しない。

## 道・川・地表

基準セル32×32px。8近傍blob47種：N=1、E=2、S=4、W=8、NE=16、SE=32、SW=64、NW=128。斜めはその両隣の直交接続がある場合だけ有効化し、正規化マスクとアトラス順を同一の定義から取得する。現行エディタは8列×6行、256×192px、未使用1セル透明。

材質の対辺を揃え、角・直線・内角・端・分岐・面を同じ素材から合成する。道・川の外側には同じ下地草の画素を使う。現行村の川は1セル中心部を24px以上確保し、川セル全体を明示通行不可にする。道の細い絵から通行範囲を推測しない。

全合法共有辺のRGBA一致に加え、3×3反復・広い面・曲がり・岸・実キャラを載せたネイティブ場面を確認する。画素一致だけでは、毎セルの不自然な枠や反復模様を検出できない。

## 木柵・生垣

直交4近傍の16種で十分な場合はblob47にしない。現行は8列×2行、256×64px。1セル占有、低い地面レイヤー。全接続辺・角・T・十字を検査する。

## 1マス橋

地面レイヤーに置く32×32pxの透過デッキ。隣の橋に応じて直線・端・角・T・十字を組む。低い欄干は閉じた外周へつなぎ、歩行の開口を横切らせない。

現行は直交16マスク＋単独縦1種＝17セル、8列×3行、256×96px。未使用7セル透明。単独ではE/Wの川隣接数がN/Sより多ければ縦、同数は横。隣接橋がある場合はその接続を優先する。端は軸の両側へ岸に降りられる見た目とする。

横から縦へは床板・欄干・境界を含むタイル全体を90度回転する。「内側だけ回転、境界だけ元へ戻す」は反復枠と途切れの原因。元の欄干とは違う列から画素を拾い、輪郭をちぎらない。

橋は占有なし、別の `bridgePassages` で下の自動川だけを解除する。橋の移動・削除・橋のみ消去で川の不可が即座に復元されることを検査する。他の物体・手動不可は保持し、最終的な手動通行可の指定は現行の優先順位に従う。

保存するのは素材IDとセル座標。接続フレームは配置の追加・削除・移動から再計算する。共有辺全組、タイル全体回転、縦横横断、単独、角・分岐、削除時判定、Undo・保存往復を検査する。

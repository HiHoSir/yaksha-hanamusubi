# Project agent instructions

When making or integrating graphics in this repository, read and follow [GitHub asset delivery](.agents/skills/github-artifact-delivery/SKILL.md) before requesting user handoffs.

Never confuse GitHub write permission with ability to transfer local binary bytes into the GitHub connector. Verify both separately. Prefer end-to-end autonomous implementation, and report accurately when the transfer bridge is blocked.

For battle-sprite modifications, preserve field character sprites and other unrelated art.

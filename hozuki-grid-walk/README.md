# 鬼灯の里・マス目と歩行 v3

16×14マス、32px、正投影トップビュー。承認済み全景を画風の参照とし、別途作成した透過素材を明示した占有セルへ配置。

- 建物7棟：2×2または3×2。樹木11本：1×2。小物4個：1×1。
- 緋月は実SDアトラス。12フレームの可視全体がセル内。背景＋キャラで描画し、前後切替なし。
- 地面は村専用のネイティブ解像度描画。フィールド用タイル画像は不使用。
- 衝突・経路探索・タップ移動・十字キーは同じ明示した整数 occupiedTiles を使用。1歩144ms、4方向。
- 各戸・井戸・橋など13地点への到達、22物体の全描画bounds/実アルファ収容、全歩行可能セルから4方向608試行をローカル検査。
- 素材の本制作への採用、本編統合、Pages公開、ブラウザ操作、Safari実機は別工程。会話・室内・イベント・セーブは未接続。

`qa/clean.png`、`qa/grid.png` が実レンダラーによる全景。`qa/check.cjs` で再生成と検査を行う。

## 生成記録

画像生成スキルと asset-design に従い built-in image_gen を1回使用。元画像は assets/objects-source.png（RGBA）。対象は茅葺きの宿・店・茶店・家・小社、細い樹木、井戸・腰掛け・壺・畑。透明背景で個別素材化し、全描画を宣言した2×2/3×2/1×2/1×1セルへ収める制約で生成。生成された区画は等幅ではないため、完全な輪郭を含む手動sourceRegionsをatlas.jsonに記録。衝突セルを画像から導出していない。

objects.png はソースのalpha<32の薄い透明ノイズのみ除去。実行時のアルファ補修なし。元画像を保持。全生成プロンプトは prompt.txt に保存。

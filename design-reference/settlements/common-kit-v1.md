# 鬼灯の里 / 共通集落キット v1

## 実装

- 48×40マス、1536×1280 world px、1マス32px。従来24×24マスの約3.33倍。
- フィールドの grass / water / road / forest / bridge / shrine / flowers を共有。
- 地面のY投影0.78、建物・人物は直立。回転なし、8方向移動と追従スクロール。
- 内部座標と投影を分離し、当たり判定は地面の座標で実施。
- 建物・樹木・人物を足元のY座標で描画順ソート。
- 川は水面上の流れを時刻で更新。橋上を除外。川や道路の静的地面はキャッシュ。

## 共通住人

12人を child / merchant / woman / teagirl / elder の5素材で構成。
`roles` は会話・役割・サービス、`resident(role,id,x,y,dir,extra)` は配置と識別子を指定。
外観typeとserviceは分離し、商人型を使う畑守り・旅人は店を開かない。
里長は進行イベントの話者名を維持。新規の専用人物グラフィックは追加しない。
向き変更用の中立4方向だけ読み込み、5系統合計20画像。歩行フレームは追加行動が必要になるまで読まない。

## 扉とセーブ

共通 `door.png` の左右をクリップし引き戸として開閉。360ms移動＋120ms保持。
アニメーション中は操作をロック。開いてから室内に入り、外へ出ると閉まる。
lastInteriorで出口と室内の役割を決定。新室内はvillageRoomで共有。
旧村revision2以前の村内セーブは南入口へ移し、進行・所持品・装備を保持。
既存茶屋・お澄の家の室内セーブは維持。

## 素材

`assets/settlements/common-v1/` の8PNGのみ新規追加（約488 KiB）。
既存村の一枚絵・旧レイヤーのネットワーク読み込みは停止。
共通建物4枚、木・井戸・畑・引き戸。画像生成ツールの透過出力をセル切り出し・縮小して配置。
生成プロンプトの主条件: 承認済み鬼灯の里案に合わせたSFC後期RPGのピクセル表現、左上光源、浅い北上固定視点、南向きの入口、屋根を切らない、背景透過、文字なし。建物は茅葺き民家・瓦屋根宿・茅葺き店・赤い暖簾の瓦屋根茶屋、共通の引き戸は独立画像。

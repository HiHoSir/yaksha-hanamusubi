# 緋月32px 画素編集・歩行候補

ユーザー編集済み `sprite-walk-4dir(1).json` を元にした確認候補です。正式採用、本編差し替え、mainへのマージは行っていません。AI画像生成は使用していません。

## 編集内容

- 正面静止画：0始まり座標 (14,16)、(17,16) の2画素だけ変更。旧RGBA [186,101,95,255] → 新RGBA [231,166,144,255]。顎付近の赤茶色を既存の肌の影色へ整理しました。目、口、前髪、角、輪郭、元の肌のベース色は変更していません。
- 正面の歩行A/B：編集前の顔を残さず、ユーザーの静止画を基準に作成。上側17行は静止画と完全一致。下側の足と袖に差分を作りました。
- 背面：既存画像を1px左へ位置合わせ。髪の外縁の暗色を正面の既存色へ揃えました。ブーツと足元を正面の高さへ合わせ、左右の足を交互に1px上げています。
- 左側面：既存左向きを基準に、目の2画素を正面の目と同じ暗赤色へ変更。目の位置・輪郭は維持。足元に暗い靴底を追加し、歩行A/Bで足幅と着地側を変えています。
- 右側面：編集済みの左向きを反転し、髪、角、目、袖、足元の不整合を解消しました。光と衣装の左右差も反転する候補なので、採用時に見た目をご判断ください。
- 肌の新しい色は追加していません。歩行中に移動する脚・手の肌画素は意図した変更で、静止画の肌を自動で一括変換していません。

## 29pxを保持した理由

最新main `97f0fc06e8fcf2d110cca0461742d870363c87af`（BETA 16.1.58）の `js/game.js` は静止画の不透明高さで計算し、`28 / bounds.height` を方向内で共通利用しています。29px素材はカメラ倍率を除き約0.965517倍、見た目28px相当となる設計です。顔や角を削る処理、画像全体の再サンプリング、ゲームの倍率変更は実施していません。本候補を実際にゲームへ接続した状態での表示測定は未実施です。

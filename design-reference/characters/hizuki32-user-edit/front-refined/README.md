# 緋月 正面調整候補 — 白妙fixed参照

基準はユーザーの `sprite-walk-4dir(1).json` 正面静止画。画風の参照は添付 `shirotae-walk-fixed.json`。新規AI画像生成は使用していません。目視承認前の正面1コマ候補です。

## 編集
- 顔・前髪・一本角の形を維持し、頭部を整数1px下へ移動。目・口のRGBAと相対配置は無変更。
- 元画像の首まわりのy=17/18の2行を除き、胴を1px上へ移動。画像の拡縮・補間はしていません。
- 顎際2画素は、既存の赤茶色から既存の肌の影色へ整理。
- 髪の外縁の暗色を強め、赤白の袖を左右対称にふくらませました。短靴を暗色＋小さい赤い結び目に整理。
- 元の肌のベース色は保持。白妙の顔・衣装の画素は緋月にコピーしていません。

- `hizuki-front-refined-32.png`: 32×32 RGBA、透過、可視外接矩形 [6,3,25,30)、可視高27px。

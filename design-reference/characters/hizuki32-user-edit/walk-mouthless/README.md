# 緋月・口なし 4方向／歩行候補

承認済み `hizuki-front-mouthless-32.png` の正面静止画を完全に保持して、背面・左右と歩行A/Bへ展開した画素編集候補です。新規AI画像生成は使用していません。元入力はユーザーの `sprite-walk-4dir(1).json`、体型の参照は添付 `shirotae-walk-fixed.json` です。白妙のファイル自体は変更していません。

## 内容
- 正面静止：承認版からの変更0画素。口なし、目、一本角、肌の色、衣装を維持。
- 背面：既存のボブと背中の衣装を使い、首まわり、袖、短靴、足元を正面と整合。
- 側面：既存左向きを基準に頭部と体型を調整。右は水平反転。角は1本、口の印は追加していません。
- 歩行：正面・背面は片脚の踏み出しと1pxの足上げに対し、反対側の袖を逆に動かしています。側面は左右の脚の前後・着地側と袖の振りを変えています。
- 全方向で上側18行の頭部は静止/A/B間で完全一致。頭の上下動・顔の描き変わりはありません。

## ファイル／方向順
`hizuki-mouthless-walk-v3.json` は再編集用yaksha-pixel-v3。方向front/back/left/right、各idle/walkA/walkB、32×32 RGBA各4096要素です。

`hizuki-walk-atlas-96x128.png` はゲーム互換の3列×4行。列＝静止／歩行A／歩行B、行＝正面／背面／右／左。

`hizuki-idle-4dir-128x32.png` は正面／背面／左／右。アトラスとは左右の順序が異なります。

個別の各方向・各コマ32px PNG、6倍の12コマ一覧、4倍GIF、元入力との差分、検査結果も同梱。GIFは静止→A→静止→B、各160msです。確認用背景はGIFと拡大プレビューだけで、素材PNGは背景透過です。

# 岩の小島・灯籠台 v1（試作）

水上灯籠用の独立した岩の土台。原画はユーザーの聖域イメージと既存灯籠を参照して生成したもので、周囲に水を焼き込まない。`source.png` は未加工の生成原画。最終96×64px PNGは、原画のアルファ24以上を保持して切り抜き、縦横比を保ち最近傍で縮小して下辺を揃えた候補。反転版は同じ原画から作成。

32px基準、表示3×2マス、接地アンカーは下段左端。occupiedTilesは `[0,-1],[1,-1],[2,-1],[0,0],[2,0]`；前列中央 `[1,0]` は別オブジェクトの灯籠を置くため空ける。灯籠を置いたときは灯籠の占有と合わせて3×2が塞がる。灯籠は土台より後に描画されるよう配置する。単独使用時は中央も別途通行不可を設定する。

原画・透過・96×64・灯籠合成・マップ内経路をローカル確認。ユーザーの見た目承認とiPhone Safariでの歩行・前後描画検査は未実施。水中石畳は別途制作する。

# Field map objects — consolidated library

This directory consolidates the former `field-map-objects-v2` and `field-map-objects-v3` without recompressing or changing PNG bytes. 32px world-cell baseline. See `manifest.json` for source sprite dimensions and `js/landscape.js` for active collision footprints.

The original v2 objects are asset candidates and are not automatically active in gameplay. Existing v3 castle, shrine, sacred tree and stone monument are the currently integrated sprites. Do not remove legacy renderers until gameplay collision and route QA pass.

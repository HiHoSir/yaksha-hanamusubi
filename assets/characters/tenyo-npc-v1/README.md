# 天妖の社の固定NPC — BETA 16.1.20

2026-10-23承認の白妙・社守の体型修正版を使用。2人とも歩行差分を持たず、会話時の正面／背面／左／右だけを切り替える。

- 白妙：長い黒髪、白い巫女装束、淡紫の裏地、赤い袴、結び札。
- 社守：小さな髷、藍色の上衣、茶色の軽い防具、腰の刀。
- `source/*.png` は生成原本をそのまま保存。白妙の原本下段は左／右、社守は右／左。配置を読み替え、反転は使用しない。
- `scripts/build-tenyo-npcs.py`（Pillow）が原本の透過帯から上下段の境目を特定する。原本中央で機械的に半分へ切ると社守の靴が欠けるため、実際の透過帯を使用する。
- 元alphaを維持し、輪郭に2pxの余白を残して切り出す。縦横比を変えずLANCZOSで縮小し、可視高232px、足元(128,248)の256pxセルへ置く。黒髪や輪郭を色抜きしない。
- 出力は256×1024 RGBA、行順は正面d／背面u／左l／右rの4行・1列。元画像SHA256、切り出し矩形、足元・縮尺をmanifest.jsonへ記録する。
- 本編では緋月58pxの96％（55.68 world単位）。足元は緋月と同じy+9×.56で、人物サイズ設定も共通。既存のNPCやフィールド緋月の素材は変更しない。
- 新しい描画は天妖の社のmiko／guardだけに限定。座標と会話・クエストは維持し、2人をstationaryにして描画と会話・当たり判定の位置がずれないようにする。
- 2画像は社への移動・保存復帰時に読み込み、読み込み完了で再描画する。移動中は2画像の準備も待つ。失敗時は既存の画像を使用し、再読込メッセージを出す。

`node qa/tenyo-npc-art.cjs`：8方向の実画像alpha、可視高と足元、左右対応、本編npc関数、歩行コマを変えても静止すること、20秒間の固定配置と会話方向の保持、重複読込なし、読込エラー時の遷移取消を検査。本編の森・鳥居のレイヤーを通した4方向の並びもnative canvasで描く。PagesとiPhone Safariの表示確認は別工程。

# new-npc — 鬼灯村の正式NPC素材

ユーザー採用済みの住人12人（目の形状修正版 eye-shapes-v2）。旧称「鬼灯の里」から「鬼灯村」への改称を、この素材セットの名称へ反映しています。

- [キャラクター対応表](CHARACTER_MAP.md)
- [機械可読の対応・寸法・ハッシュ](manifest.json)

## 画像規格

各PNGは透過RGBA **96×128px**、1コマ **32×32px**。大人の可視全身は最大28px、子どもは最大24px。可視全体をセル中央へ配置します。足元をセル中央へ置く規格ではありません。

| 行 | 向き | 既存direction値 |
|---|---|---|
| 0 | 正面 | d |
| 1 | 背面 | u |
| 2 | 左 | l |
| 3 | 右 | r |

| 列 | パターン |
|---|---|
| 0 | 歩行A |
| 1 | 静止 |
| 2 | 歩行B |

再生順は **0→1→2→1**、初期目安160ms／コマ。停止は列1。拡大表示は最近傍補間を使います。左右は反転で統一しており、片側の髪飾りや斜め紐も反転します。

## 採用版と検査

白目補完後、川仕事の老人・社の世話役・お澄の左目、および広場の子の右目を修正。正常側を基準に白目・黒目の幅と高さをそろえ、正面3コマに適用した版です。承認前の候補と取り違えないでください。

12画像・144コマの寸法、非空アルファ、可視全身のセル内収容、透過値0/255、左右反転、目形状を確認。SHA256・Git blob SHAをmanifestへ記録しています。

**本編接続:** `js/hozuki-village-game.js` が屋外8人・屋内担当4人を個別NPC IDで読み込みます。鬼灯村の配置・当たり判定は明示セル、会話・サービス・物語進行は既存データを継承します。原画のバイト列は変更していません。検査と接続仕様は `docs/hozuki-village-game-integration.md` を参照してください。Pages・iPhone Safariは別の検査段階です。

元の生成・正規化・目修正の履歴は、この会話で納品した素材一式ZIPに保持されています。本ディレクトリのPNGが今回採用された最終バイト列です。再生成・再縮小で承認画像を上書きしないでください。

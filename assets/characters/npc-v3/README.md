## 素材仕様
PNG RGBA 576×896、192×224セル。行＝正面/背面/左/右、列＝歩行A/直立/歩行B。可視高192、足元(96,212)。既存描画計算を維持し、村では58pxの緋月に対して大人96%・子ども76%の高さとする。

正面と背面はA反転からB、左向きは右3枚の反転。お澄の右Aは左Aの反転を採用（元の右Aは腕の位相がBと重複）。腕の付け根と脚の所属をたどり、同じ側の腕と脚が反対へ振れることを確認する。髪の跳ねの反転は許容。衣装の小さな差を人物変更と混同しない。

設定「村人の素材」で新イラスト/旧素材を比較する。選択はURLのnpcArtパラメータに保持。新素材が未ロードならv2へフォールバック。セーブ形式には追加しない。

# 山の分化と和風装飾 / β15.55.37

通常の山は緑に覆われた新しい山へ変更。旧 mountain.png は岩山として保存し、その形を参照して雪山を別途生成した。いずれも96×88px、左上光源、透過PNG。山頂・尾根と植生の面で森の樹冠と区別する。

| 素材 | 実寸 | 用途 |
| --- | --- | --- |
| greenMountain.png | 96×88 | 緑の通常山 |
| snowMountain.png | 96×88 | 岩山を元にした雪山 |
| shrine.png | 64×64 | 森のそばの祠 |
| lantern.png | 24×40 | 祠の両脇の石灯籠 |
| bridge.png | 96×40 | 左右の岸をつなぐ木橋 |
| flowers.png | 40×24 | 草原の花と草むら |

岩山は assets/terrain/landscape-v1/mountain.png をそのまま使用し、荒地に配置。地形データは mountain / rockMountain / snowMountain を別種として扱い、隣り合っても同じ画像にまとめない。

装飾は地形から独立した座標で配置。橋・花は地表レイヤー、祠・灯籠は足元Yによる奥行き順。検証中は全地形を通行可能で、祠のイベントや橋限定の通行制御は追加しない。

組込画像生成ツールでオリジナル素材を制作。雪山のみ旧オリジナル岩山を編集対象とし、それ以外は新規生成。制作プロンプト: art-source/landscape-v2-prompts.txt。ゲーム用サイズへ最近傍縮小、16色以内・alpha 0/255に整理。ROM由来画像を含めない。

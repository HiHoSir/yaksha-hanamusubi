# オリジナル地形セット v1 / β15.55.36

β15.55.35で承認された森の見た目を基準とする。画像寸法32pxの制限はユーザー指示で解除。移動マス32px、樹冠80px表示、山96×88px表示。左上光源・疑似見下ろし・限定色・二値alpha・最近傍描画。

| PNG | 実寸 | 用途 |
| --- | --- | --- |
| mountain.png | 96×88 | 山脈・雪原上の山。透過オブジェクト |
| water.png | 64×64 | 海・川・湖の共通水面 |
| sand.png | 64×64 | 海岸・川岸の砂地 |
| snow.png | 64×64 | 雪原 |
| barren.png | 64×64 | 荒地 |

組込画像生成ツールで5素材を個別生成。生成指示は art-source/landscape-v1-prompts.txt。生成原画を最近傍縮小し、山16色以内、地表6色以内（雪は2色、砂4色）に整理。山は背景透過、それ以外の基礎地表は不透明。地表の対向辺をピクセル一致させる。

js/landscape.js が地表の8近傍から凸角・凹角・岸をピクセル単位で合成する。岸を含む合成タイルは実行時にキャッシュ。64px地表は4象限を交互に使って模様の縮小を防ぐ。海と川は同じ水域として接続する。山と森、夜叉姫は足元Y順に描画。

今回の対象は基本自然地形。町・城・祠などの建造物、通行制限、地形効果、波アニメーション、本編への置換は未実装。既存の森比較・旧32px接続検証はDEBUG MAPの後続ページに保持。ROM画像は一切含めない。

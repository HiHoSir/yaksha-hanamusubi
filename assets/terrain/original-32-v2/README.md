# 夜叉姫 草原base＋森9（β15.55.34）

基準: 「夜叉姫_Work引き継ぎ_ROM解析.md」2026-10-07版の確定事項（11・14・16・18〜21節）。草原は基本1枚、森は内部＋四辺＋四隅。実ゲームは32pxセル、内部は16px部品×4。CE01を16×8とする旧仮説は使わない。ROM画像は一切含めない。

全10枚は実寸32×32 PNG、RGBA。透明画素と不透明画素だけを使用（alpha=0/255）。森は9色以内、草原は2色。アンチエイリアスなし。森の輪郭外は透明で、草原の地色は描き込まない。

草原baseは地色 #83b54d に重ねる薄い模様の透明レイヤー。透明地形を合成するため、描画側が最初にこの地色を塗る。草原を全面透明のまま空白表示にしないこと。

生成画像をデザイン原画として使い、32×32へ最近傍サンプリング、7色固定パレット・alpha二値化・外周接続を調整。制作原本は art-source/forest-core32-v2.png。tools/build-forest32.cjs は樹冠全体を維持し、露出した辺だけを透過輪郭で切って9枚を出力する。再生成: node tools/build-forest32.cjs（@napi-rs/canvasが必要）。

各象限は元画像の同じ位置から取り出す。中央の左上16×16を4回繰り返す旧方式を修正し、32×32全体の樹冠を表示する。

js/autotile.js は納品32px PNGから16px象限を取り出し、隣接で選択して実寸で描画する。9枚に当てはまらない孤立・細い帯も象限合成で扱う。斜め凹角の専用チップは未実装。

検査: 32px寸法、全枚に実透明画素、半透明なし、色数、内部/四辺/四隅の接続辺一致、16隣接マスク、本編セーブ不変。山・海岸は今回の対象外。本編地形への反映は実機確認後。

# フィールドのマス整合・道中施設（BETA 16.1.50）

- 物理位置は32pxセル中央。通常／速い設定のどちらも1歩32pxとし、速度は補間時間だけを変える。既存の端数位置は同じセルの中央、通行不可なら最寄りの安全な中央へ復帰する。進行・所持品は維持する。
- フィールドの緋月は村と同様、可視全体の中央をセル中央へ置く。採用済みSDの可視28px、方向共通のアンカー、球面投影、地面高さを維持する。
- `contactTiles`／`occupiedTiles` は整数セルの明示値。山の削除・森への置換を終えてから `refreshCollision` で衝突索引と到達可能範囲を再計算する。消した物体の判定を残さない。
- 道案内の地蔵4体は各1セルを占有する。セルに侵入できず、到達可能な正面の接近セルから会話できる。
- 道中4施設は既存オブジェクトの `restStop` と `contactTiles` に重なって自動入場する。Aボタン／近接距離では入場しない。補間完了後の暗転・素材待機を使う。
- 宿は新しい宿マップ、茶屋は新しい茶店マップ。施設固有の住人名・会話を維持して整数セルへ配置し、宿主の回復とセーブ復帰を引き継ぐ。室内の出口へ踏み込んで暗転帰還し、入口外の安全なフィールド接近セルへ戻る。
- フィールド出入口と村6施設、地形・崖・梯子、保存データの検査を独立して行う。Native Canvasの反復描画テストは各シーンの出力キャンバスを解放してから次へ進む。実機Safariの確認はPages公開後に行う。

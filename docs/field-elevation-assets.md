# フィールド高低差・素材制作の引き継ぎ仕様

## 採用済みの基準
- 1マス32×32px、4方向のマス移動。凸角の切り込みは辺30px、面積450/1024＝約44%（約45%設定）。
- 削った三角領域と境界は上下どちらからも侵入不可。足元の余裕2px。隣接する角同士が重なる場合は各15pxに制限。
- 地表・高さ・坂方向・崖面素材は独立。描画と移動判定は `js/elevation-model.js` の同じ輪郭を使う。
- 凹角、異なる下段高さ、坂と接する角は直角を維持。対応していない接合を見た目だけで隠さない。

## 今後作る素材
| 種別 | 制作と配置の契約 |
| --- | --- |
| 地表チップ | 32px単位の真上から見た反復可能な地面。高さや遠近、角落としを絵へ焼き込まない。草・砂・雪などを交換しても形状は共通。 |
| 崖面 | 地表とは別テクスチャ。横の連結と上下の反復を確認。直線・斜め面へ同じ位相で貼る。専用素材未制作の間は既存岩素材を使う。 |
| 道・低い装飾 | 地面に合成し、地表と一緒に高さを付ける。独立した遮蔽物にしない。 |
| 木・社・山など | 真の透過PNG。見た目寸法、足元アンカー、整数の `contactTiles`、整数の `occupiedTiles` を別々に指定。 |
| 橋 | 橋面の明示マスを通行可能にし、両岸との高さを一致させる。川素材を消して橋に見せない。 |

現在の本編ローダーでは雪・砂・岩・水は64×64px（32pxセルの2×2）、草は256×256px。新しい32pxチップは宣言したシートへ組み込むか、`landscape.specs` とサンプリングを同時に更新する。寸法検査を外して読み込ませない。

## 新規配置
1. 現在の `main`、AGENTS、関連スキル、実際のレンダラーを読む。
2. 接地マスを平らな同一高さへ置く。坂や削除三角領域をまたぐ基礎を作らない。
3. 衝突は明示 `occupiedTiles` のみ。画像サイズや影から算出しない。入口の前は空ける。
4. オブジェクトの描画高さは接地マスの高さを使う。描画用footは深度順に使い、高さ推定に画像下端を使わない。
5. 新しい道・入口を経路検査へ追加する。坂は両端の辺全体が隣接地形に連続すること。
6. 静止画で接地・遮蔽・斜め崖の穴を検査し、歩行・往復・古いセーブ復帰を別に検査する。

## 実装箇所
- `js/elevation-model.js`: 共通輪郭、高さ、全歩幅の通行判定。
- `js/field-elevation.js`: 本編の高さ調整、道・入口・オブジェクト基礎の接続。
- `js/elevation-view.js`: 共通投影による地表、崖、物体、キャラクターの描画。
- `js/world.js`: 本編の地形、移動、セーブ座標の安全な復帰。
- `js/game.js` / `index.html`: 本編呼び出しとロード順。

`elevation-lab.html` は素材比較用。採用の判断は本編でも確認する。

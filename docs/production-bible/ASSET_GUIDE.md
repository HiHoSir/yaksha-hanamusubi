# ASSET GUIDE — グラフィック制作と納品
## 必須手順
一次資料の確認→参照画像指定→生成→比較検査→素材分離→PNG/WEBP最適化→アトラス/manifest→GitHub配置→実機/CI確認。生成画像をそのままマスター認定しない。
## 主人公
緋月の金一本角は額の中央より上。活発な表情。赤い大きなリボン・和風旅装。顔・比率・角・髪型・配色は**ゲーム実装済み戦闘画像**と`CHARACTER_BIBLE.md`で検証。全方向と戦闘姿の整合性。足元アンカーで倍率調整。
## 敵と変異種
ゲームに登録済み画像の線と塗りを主人公にも参考適用。既存変異種の欠損衣装バリエーションは再導入しない。透過処理を重ねて輪郭や内部色を消さない。原寸検査とゲーム表示検査は別。
## フィールド
32pxチップ、SFC後期のドット感、ベベルビュー。地形の連続性・境界・当たり判定・カメラ滑らかさを検査。
## 村・屋内
パース図→歩行/衝突/深度/遮蔽データ→同じパース基準で背景/中景/前景/FXを制作→画像合成比較→ゲーム実装。背景に焼き込まれた家具を別生成画像で二重描画しない。左右移動時のマスク判定とNPCの足元を一致させる。
## 納品
編集可能な原本、ゲーム用バイナリ、レイヤー構成・座標・寸法、参照元、sha、実機検証結果を残す。GitHubバイナリ転送は`AGENTS.md`と`.agents/skills/github-artifact-delivery/SKILL.md`を参照。

# CHANGELOG POLICY — 設定変更と反映
更新エントリ必須項目: 日付、分類、変更理由、変更前/変更後、承認者/状態、影響を受けるファイル、必要な画像再生成、互換性、QA状況、コミットSHA。
## 初期記録（2026-10-09）
- 名称: 緋月 / 鬼哭の花契りを正式表記。
- 主人公: 一本角・金色・額中央上を固定。活発さ優先。ゲーム実装済み戦闘絵と敵変異種の画風に寄せる。
- 髪の長さ: 現行 `CHARACTER_RULES.md` の短髪と、承認済み新設定画の長髪が相違。ゲーム用素材の一括更新は**未実施**、解決まで差分を追跡する。
- 変更したのは制作文書であり、ゲーム内のキャラ画像やシナリオを置換していない。
## リリースゲート
タイトル入口QA、変更関連QA、リポジトリ内ファイル実在確認、画像の実機目視検査。PASSの根拠がない項目は未検証として公開する。

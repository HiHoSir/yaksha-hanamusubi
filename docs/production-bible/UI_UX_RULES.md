# UI/UX RULES — iPhone Safari第一
## 最優先
タイトルの「はじめから」「つづきから」が常にタップ可能。タイトル表示中は仮想十字キーがメニューを隠さず、ゲーム開始後は必要な操作が表示される。
8方向移動、A決定、B戻る、会話・戦闘・衣装画面のボタン競合を禁止。safe-area・短い画面高・画面回転に対応。メッセージ送り時に勝手に移動しない。
## 動画/音/素材
起動速度と可読性を優先し、待ち時間とCPU負荷を測る。高解像度多層画像は室内ごとに読み込み、不要時は適切に開放。古いセーブを消去しない。
## QA
タイトル入口テストは毎回。変更箇所に応じ局所smokeを実施。根拠のない「実機確認済み」は書かない。

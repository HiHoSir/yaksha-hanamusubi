# PROMPT GUIDE — AI生成の実行仕様
## 毎回入力すること
目的、対象シーン/キャラ、参照元ファイル、確定設定、可変範囲、禁止事項、成果物形式、検査条件、GitHub配置の要否。参照画像を確認できない場合は推測で画風一致を主張しない。
## 画像生成テンプレ
「『鬼哭の花契り』の緋月。ゲーム内戦闘スプライトを主参照、実装済み敵変異種を画風の副参照にする。**額の中央上に小さな金色の一本角**。赤い大きなリボン、紫系の髪、赤白の和風旅装。好奇心旺盛で活発、明るい笑顔と俊敏さ。過度なカードゲーム風の光沢・長大な装飾・二本角・左右にずれた角は禁止。方向別の同一人物性、服のつながり、足位置、輪郭の透過を検査。現行実装素材と異なる髪の長さは必ず差分として報告。」
## シナリオ生成テンプレ
「『鬼哭の花契り』第1章で、緋月が主体的に村人の記憶の異変を追う小イベントを作る。SCENARIO_BIBLEとjs/data.jsのクエスト順・既存NPCを維持。コミカルな生活描写から静かな違和感へ。条件、会話、フラグ、再訪台詞、次の目的、旧セーブ互換の検査を添付。」
## 部屋生成テンプレ
「室内のパースガイドとwalk/depth/occlusionの制御データを先に定義し、同じ投影規約の下でBG/MID/FGを別々の透明素材にする。合成後に元の完成図と比較し、柱や家具の二重焼き込みを禁止。」
## レビュー
顔・一本角・装束・リボン・敵画風との距離、三面図の整合、誤字、フラグ互換、画像欠落・Alpha破綻の各項目をPASS/FAIL/未検証で報告。

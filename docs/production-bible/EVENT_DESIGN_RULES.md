# EVENT DESIGN RULES — 人と場所に意味を与える
イベント種類: メイン・村人会話・探索・収集・戦闘・休息・環境演出。
## 最小設計
trigger（A/タップ/接触）、条件、話者と会話、変わる状態、報酬、再訪時の台詞、終了後の次の行き先。難所には地蔵等の案内役を置く。
村人の暮らし（畑・茶屋・宿・織物・川仕事）に紐づける。野菜を調べてランダムで手に入るなどのささやかな発見を許容するが、資源の無制限入手やセーブ状態破損を避ける。
## 動作
歩行、会話中停止、戦闘への遷移、メニュー優先度、屋内への出入り、イベント再発火を検査。見た目のオブジェクトと衝突範囲を一致させる。プレイヤーに隠し条件だけを要求しない。

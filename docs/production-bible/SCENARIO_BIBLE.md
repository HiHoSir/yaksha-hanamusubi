# SCENARIO BIBLE — 第1章を壊さないシナリオ制作
## 作品の中心
忘れた約束、縁、記憶、人と鬼の隔たり、各地を巡る旅情。前半は温かな暮らしと小さな笑い、後半は感情的選択と別れ。説明台詞ばかりにしない。
## 現行の章【実装】
`js/data.js`のstory配列が第1章『花の声が消える里』の現行進行。里長→白妙→潮平→旅の薬師→滝童→白狐の使いの**順序・クエストステージ番号・エリアID**は旧セーブ互換上維持。章の後続展開は未実装。
異変は鈴が鳴らないだけではなく、人々が道や約束を思い出せなくなること。花契りは憎しみを鎮めたが、失われた大切なものもある、という情報を段階的に開示する。
## 起承転結の基準
各イベントは「生活・小さな異変→緋月が動く→行動・探索・対話→新しい事実→感情的余韻と次の導線」。悲しみや危険にも自然な軽口・優しさで緩急をつける。緋月は活発かつ主体的。黒幕、血統、エンディングは未確定なので捏造しない。
## NPCの台詞
人物ごとの一人称・社会的立場・関係と、その土地の生活に根差す台詞を優先。里長は年配の言い回し、白妙は丁寧、潮平は率直、滝童は子どもらしく。村人を単なる道案内ロボットにしない。
## 変更時の禁止
- 既存セーブ互換を壊すクエスト順変更
- 承認なく主題を恋愛主軸・残虐さ・現代ネットミームへ転向
- 伏線の種明かしを序盤で説明しきる
- 緋月を終始無口・冷静・受け身にする
## QA
`js/data.js`のstory/objectiveの段数、移動先、会話話者、終点を比較。タイトル新規開始、既存セーブ読込、会話進行、ボス戦後の復帰を回帰チェックする。

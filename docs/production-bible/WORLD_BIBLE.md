# WORLD BIBLE — 世界観・地域と昔話
## 公開版の方針
日本昔話・鬼・妖怪・地蔵・社・祠・花・川・海・森を核にしたオリジナル和風RPG。原作ROM由来の画像/音声/タイルの流用は禁止。解析結果は検証・構成参考に限る。
## 現行エリア【実装】
鬼灯の里 / 花霞野 / 花見茶屋 / お澄の家 / 里の建物 / 天妖の社 / 海の入り江 / 忘れの森 / 龍神の滝 / 月見の湯 / 九尾の祠。正本は`js/data.js`。地形座標・接続・出口は実マップと照合。
## 地理と暮らし
里には畑、織り、川仕事、宿、茶屋、商いがある。草木・天候・川音・小道は背景ではなく生活や物語に影響する。地蔵や野菜も調べる意味があり、地名や伝承は世界の記憶と結び付く。
## 妖怪観【提案】
妖怪は一律の悪役ではなく、土地や人の願い・忘却に関わる存在として描ける。ただし新しい世界法則は提案ラベルを付け、既存の章設定と矛盾しないか検査する。
## 新大陸
既存のオリジナル地図「新大陸」を第1章に関連する地域として尊重。別地域の地理を変更するときは現在の世界地図・実装上の訪問順と整合すること。

# STYLE GUIDE — 表現基準
## 視覚
世界の基準は和風RPGの温かさと少しのコミカルさ、後半の切なさ。敵変異種と主人公戦闘絵で線・明暗・彩度・キャラ比率の整合を取る。ソシャゲ高レアカード風の過剰な装飾や無根拠な衣装改変は避ける。
フィールドのみ32x32チップとSFC後期のドット美術を維持。村・室内・自然名所の画像解像度・レイヤー枚数に固定上限なし。ただしiPhone Safariメモリと表示速度を測る。室内は共通パース・歩行・遮蔽を先に設計し、そのパースに従い画像を分層。
光源は原則左上、影は右下（フィールド）。室内演出では具体的な窓・灯籠の位置を優先。被写体に描き込み過多・画風の断絶がないこと。
## 文章
平易で読みやすい日本語。話者固有の口調を守り、地名説明のためだけの不自然な独白を避ける。日常会話の笑いと物語の余韻を両立。
## UI
可読性最優先。濃紺・金のUIと和風モチーフ。見えないメニューや長過ぎる演出を許容しない。

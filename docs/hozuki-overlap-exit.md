# 鬼灯村：出口の重なり遷移と一歩北の出現点 — 16.1.35

南端の歩行可能な3セル `(9,17)`、`(10,17)`、`(11,17)` は、通常の一歩で重なった時点で既存の暗転処理を開始しフィールドへ戻る。中央も左右と同じ `move → exitArea → requestAreaExit` の経路を使う。

入場時の即退出を避けるため、本編の出現点を1セル北の `(10,16)`／pixel `(336,528)` とする。これにより入場後は待機でき、南へ一歩で出口に重なる。元の添付layout/collision/PNG、NPC配置、南端の通行可否は変更しない。既存セーブの有効な現在位置は維持し、旧版で既に南端に保存された場合の南入力による退出処理も残す。

旧出現点を前提とする本編往復検査を更新し、変更前に失敗を確認した。新出現点の非出口、3出口への到達、3セルすべてへの通常歩行による自動退出、安全なフィールド復帰、入場後の待機を実コードで検査。関連19検査PASS。Pages公開・配信コード照合・iPhone Safariは別工程とする。

# 室内建築アセット共通規格：柱・壁（3層構造）

状態：**制作仕様／未実装**。茶店・宿屋・兵具屋・民家に適用。柱の詳細は [interior-pillar-asset-standard.md](interior-pillar-asset-standard.md)、既存の遮蔽原則は [interior-occlusion-layers/SKILL.md](../skills/interior-occlusion-layers/SKILL.md) に準拠。

## 絶対条件

- 室内配置は **1タイル=32px**。建物サイズの検証基準は茶店10×8、宿屋16×12、兵具屋10×8、民家8×7（すべて検証中の値）。
- **建築物の床接地部・中間部・上部暗部を3層に分ける**。別PNGとする場合でも、接続する木目・壁面・輪郭がずれない共通座標と切り出しオフセットを保持。
- カメラは**奥で縮小・手前で拡大**。意図しない横湾曲や画面中央への吸い寄せは入れない。物体と人物は同じ投影基準・足元位置でスケール計算する。
- ぶつかり判定は**床接地範囲**から定義。見た目の全高、上部暗部、影から衝突領域を導出しない。
- 3層に分ける目的は**不必要な遮蔽を減らすこと**。黒い上部を常時最前面に固定するなど、キャラクターの可視性を損なう描画順は禁止。
- 元絵と色調・木目・輪郭のつながりを保つ。製品表示に矩形の仮色や抽象図形を代用しない（検証ページの明示的なデバッグ表示は除く）。

## 3層の役割

| 層 | 柱 | 壁 | 衝突／描画 |
| --- | --- | --- | --- |
| **01 床接地部 (base)** | 根元と必要最小限の影 | 壁下端・床との接続、巾木相当 | 足元のフットプリントを持つ唯一の層。影は原則床へ |
| **02 中間部 (middle)** | 木目の連続する柱胴 | 木壁・土壁・漆喰など、連続する壁面 | 接地部の深度を基準に、人物や他オブジェクトと適切に遮蔽を分離 |
| **03 上部＋暗部 (top_dark)** | 天井へつながる柱の暗部 | 天井・梁方向へつながる暗部 | 衝突なし。描画は見通しを優先し、必要ならカメラの表示範囲で切る |

上部は「上面が露出した杭や板」のような視点にならない。木口や厚い天端を不自然に見せず、暗部へ連続させる。

## 壁の横方向の接続規格

- 壁は1タイル幅を基本接続単位とし、単一の壁セルを繰り返せるようにする。**見た目の高さは1タイルに制限しない**。高さは58px基準主人公と実画面比較して確定。
- 同じ高さと奥行きの接続部分を、**中央（連結）、左端、右端、内角、外角、出入口左右端**として区別。左右反転を使うのは木目や光源の不自然な逆転がない場合だけ。
- 接続部は輪郭、木目、明度、暗部グラデーションが左右の境界でつながり、拡縮時も隙間・段差・二重線を作らない。
- 角部・L字の壁は一つの巨大前景にまとめず、**方向と奥行きの異なる区間で分割して描画順を制御**する。
- 出入口は通行可能なセルと判定し、見た目上の敷居・踏み石・段差を別の床アセットとして扱う。通常の壁セルの不可侵範囲が出入口へはみ出さない。
- 左右の壁は室内で不必要に高い遮蔽物にしない。奥の正面壁との交点は自然に接続し、人物・家具が読める構図を優先。

## 足元、判定、投影

次の3種類を必ず独立管理する。
- `visual`：実画像の輪郭、構成パーツごとの描画基準オフセット
- `footprint`：侵入不可の床セル・接地ポリゴン（壁の場合は接続された実占有セル）
- `depthAnchor`：人物・NPCと比較する**ワールド空間の足元Y**

高さ表現・見た目の正面面積は `footprint` に影響しない。移動中の人物は描画済み補間足元Yで奥行きを比較。奥壁の背面は原則歩行空間ではないため、柱と同じ汎用透過処理を機械的に適用しない。背面を通る構造や通路があるときだけ、適切な深度分割と遮蔽を加える。

壁・柱・床の段差は村内の高さ表現を参照し、**土間から板の間へ上がる踏み石は通行可能**。別体の「上がり框」アセットは茶店では**制作・配置しない**。

## アセット名／メタデータ案

```json
{
  "id": "wall_wood_segment",
  "tileX": 2,
  "tileY": 1,
  "orientation": "north",
  "connector": "center",
  "tileSpan": [1, 1],
  "footprint": [[2, 1]],
  "depthAnchor": { "x": 2.5, "y": 2 },
  "layers": {
    "base": { "src": "wall_wood_base.png", "offsetPx": [0, 0] },
    "middle": { "src": "wall_wood_middle.png", "offsetPx": [0, 0] },
    "topDark": { "src": "wall_wood_top_dark.png", "offsetPx": [0, 0] }
  }
}
```

このJSONは**契約例**であり、現行ゲームがすでに読み込めるデータ形式を示すものではない。オフセット・実ファイル名・柱幅・壁高・当たり判定幅は実素材とゲーム画面から決定する。

## 制作・受入手順

1. 茶店の**奥壁の中央セル1枚**を先行制作。足元、正面の中間壁、黒い上部の3層で構成。
2. 1セルを複数横につなぎ、木目・輪郭・暗部・足元の接続ずれがないか確認。
3. 左右端・角・入口へ広げ、柱と隣接した箇所で3層が自然に接続するか確認。
4. ゲーム本編の主人公画像（高さ58px基準）を前後左右に置き、奥と手前の縮尺差、視認性、家具との比率を確認。
5. 衝突検査：壁は指定セルのみ通行不可、出入口と踏み石は通行可能、角で半マス停止や1セルずれなし。
6. 3層合成で継ぎ目・色ズレ・余分な背景・ハローがないことを確認。実際の室内カメラで、上部の過剰遮蔽がないことも確認。
7. 茶店承認後に宿屋・兵具屋・民家へ共通化。制作、GitHubアップロード、Pages表示、Chromium/iPhone Safari実機確認を**別々の検証工程**として記録。

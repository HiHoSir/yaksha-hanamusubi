# 花見茶屋・レイヤー再設計（作業中）

## 現行実装の確認
- 正本: `assets/interiors/base-v1/teahouse.webp`。元画像を保持し、旧実験用 `tea-*.webp/json` は流用しない。
- 描画: `js/interior-base.js` は768×768の画面に元画像を `(0,128,768,512)` で表示する。
- 主人公: 論理高さ58px、移動単位32px。室内カメラと共通の描画倍率を維持する。
- 現行の茶屋は静的背景のみ。深度オブジェクトは武具屋カウンターだけ。
- 現行の茶屋の当たり判定は矩形4個で、画像と一致するか未検査。

## 採用予定の分離方式
1. **背景**: 壁、床、カウンター、座布団、固定装飾を1枚の画像に統合する。座卓の背後は元画像に忠実な床を復元する。
2. **座卓4台**: 元画像由来の正確な輪郭を切り出したRGBA素材を使用。各座卓は接地面2×1マス（64×32px）を基本とし、視覚輪郭・接地面・深度アンカーを独立管理する。
3. **入口暖簾**: 必要な箇所のみ固定前景にする。柱は通行不可にして不要な前景化を避ける。
4. **描画**: 緋月とNPCの補間中の足元Y座標、座卓の接地アンカーYを同じキューでソートする。暖簾はその後に描画。
5. **安全性**: すべての画像の読込完了まで元の茶屋を表示。既存のセーブデータと出口遷移は維持。

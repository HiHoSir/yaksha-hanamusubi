# 『鬼哭の花結び』装備性能設計案 v1

> **2026-11-13／未確定・設計案・本編未反映**。ヒヅキのB式v2（添付 `hizuki-status-v2.json`）を正とし、T0〜T6の合算ボーナスは変更せず、T7・T8だけ追加案とする。装備名称は未確定。時期は販売設計書と整合させる。

## 設計ルール

- ヒヅキは単独行動。物理ダメージ `floor(攻/2 - 守/4)`（乱数・最低保証は別処理）。攻＝素の攻＋武器補正＋覚醒補正、守＝素の守＋頭・胴・足の補正＋覚醒補正。
- 既存コード `js/equipment.js` のスロットは武器・頭・胴・足。ただし実装内の旧アイテム補正（+2,+3等）と現在のB式v2表（+20,+42等）は**違う体系**。名前やIDが同じでも現行コード数値を確定値と見なさない。
- スロットを減らしたり、見た目を強制変更しない。既存の杖・足袋・特殊効果装備は**旧実装資産として保持**、B式v2での代替品・特殊効果は別検討。
- T0〜T6の守の総補正は**確定資料の数値**。部位別の配分は今回の**新提案**。
- 最終到達目安は段40、段99上限はそのまま。

## 検証結果

- 段18 T3→T4：木霊が4発→3発。段30 T5→T6：妖狐が4発→3発。装備更新が明確に効く。
- 段35 T6→T7、段38 T7→T8、段40 T7→T8：対象通常敵に対して撃破回数が変わらないことがある。上位tierの価値は防御力・ボス戦の短縮・術技の節約まで含めて検証。**通常敵の体力を意味なくインフレさせて装備差を演出しない**。
- 段38終盤Bの攻134のままT8を着ると、被ダメは12（最大体力342の3.5%）で複数型の目標6〜9%から外れる。**攻158**にするなら24（7.0%）となるため、敵データに修正候補として記録。敵確定数値への自動反映はしない。
- 段40・T8では未確定の第三覚醒補正をまだ足していない。終盤のバランスはそのイベント値が決まったときに再計算する。

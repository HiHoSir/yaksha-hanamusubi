## 旧v2原本と、その後の決定の関係

`hizuki-status-v2.json` はユーザー添付の **2026-11-12時点の原本を改変せず保存**しているため、当時の未決項目や例示術名を含む。後続の明示決定が優先する：

- ラスボス想定は **段40**、段数上限99は維持（原本の「段50にするか」は解決済み）。
- 敗北時は **所持両25%減・最後に訪れた町に戻る**（原本の `death_penalty_open` は履歴情報）。
- 覚醒は**物語連動型**。段10・25・36〜38は目安であり、具体的シナリオイベントは未照合。最終能力補正も未決。
- 原本の鬼火・火天などの `arts_examples` は初期例示にすぎない。現在の**12術暫定候補**は別紙 `spell-candidates-2026-11-13.md` を参照。「花結び」「花契り」は通常術にしない。

原本のフィールドを勝手に変更して矛盾を隠さない。**確定・未確定の後続決定は統合JSONに別の根拠として残す。**

1. 出現分布と既存マップの地理・シナリオの整合。旧データ中の「花契り」や他作品由来の筋書きを正史として流用しない。
2. 段18のT4を森の強敵より先に入手できること。T3とT4が近すぎる販売導線を解消。
3. 終盤T7・T8の必要性と第三覚醒の未定能力を一緒に再検算。
4. 店の在庫、取得両、心、死亡時25%所持両減額を同じ期待収支で検証。
5. 既存セーブ移行・装備IDと四部位スロット維持・中断再開の安全確認。数値JSONの追加だけでは本編に反映されない。
6. GitHub Actionsは**ワークフローを作成しただけでは合格を保証しない**。結果ページ・Node実行結果・iPhone Safariの実戦をそれぞれ検査。

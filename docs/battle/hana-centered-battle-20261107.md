# 鬼哭の花結び — 単独主人公・中央手前戦闘UI

更新: 2026-11-07。『鬼哭の花契り』の4人パーティ案と混同しない。

## 承認事項と参照
- 主人公は緋月のみ。仲間枠の表示なし。
- レイアウトは『大貝獣物語II』を参考にした奥行き構図。**緋月は画面中央手前**、敵は**奥・少し右**。作品固有の画像やUIは複製しない。
- 画面下部のメッセージ・コマンド窓が緋月の脚や裾を隠すのは許容。頭部・金角・肩・上体は読めるようにする。
- 背景はゲーム既存の `assets/scenes/battle-grass-v1.png`。新規画像生成なし。
- 戦闘ロジック、保存、フィールド移動、BGM、コマンドの意味は維持。

## 採用候補の戦闘用画像
`assets/characters/hizuki/hana-20261107/battle/` 下の真正RGBA・512×384:
- `battle-idle-512.png` 待機
- `battle-attack-512.png` 刀の物理攻撃
- `battle-skill-512.png` 術攻撃
- `battle-hit-512.png` 被弾
- `battle-guard-512.png` 刀で防御
- `battle-victory-512.png` 正面向き勝利

`js/game.js` の `HIZUKI_HANA_BATTLE` が各画像をプリロードし、`battlePose` に応じて切り替える。未読み込み時の既存素材フォールバックを残す。レベルアップ専用絵は別途移行まで既存のまま。

## 配置と操作
- `#battleHeroOverlay`: fixed RGBAフレーム中央（`left:50%` と `translateX(-50%)` の組合せ）。画面高さと向きで`bottom` / `width`調整。
- `enemyArt(bg,535,155)`: 768×430内部キャンバス座標。FXの基準点も同じ位置へ変更する。
- 上段: 戦闘状況・ターゲット時だけ敵名。
- 下段: 緋月1人の体・技、会話窓、戦う/術/道具/守る/逃げる（サブメニュー時は戻る）コマンド。
- 縦は3列コマンド、横は6列。操作対象は画面端・セーフエリアでも44pxを目安に確保する。
- 緋月はエフェクト以外で横方向に再配置しない。足元が下部HUDと重なっても原画像をトリミングしない。

## QA / 公開
- `qa/battle-hero-layout.cjs` で6ポーズ＋レベルアップ・縦横5サイズ・セーフエリアを検証。
- `qa/battle-layout.cjs` でタッチ対象、メニュー遷移、アイテム操作等を確認。
- Actions成功とPages公開は独立。現行Pagesの改善ブランチ公開allowlistはこのブランチを許可しないため、**検査が合格しても正式Pagesに配置したとは報告しない**。
- iPhone Safariで実機画面の上体視認性、ボタン重なり、各ポーズ、敵・FXの前後関係を確認し、ユーザー承認後にmainへのマージとβ番号更新を行う。

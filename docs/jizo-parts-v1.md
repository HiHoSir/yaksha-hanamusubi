# 地蔵チップ v1

独立オブジェクト。既存の村の視点・灰色の石肌・赤い前掛けを継承する。

| ID | 内容 | PNG/表示 | 接地・占有 |
| --- | --- | --- | --- |
| jizo_small | 既存 `assets/terrain/places-v1/jizo.png` の再利用 | 32×32 / 1×1 | [[0,0]] |
| jizo_kasa | 笠をかぶった合掌地蔵 | 32×32 / 1×1 | [[0,0]] |
| jizo_bosatsu | 錫杖と宝珠を持つ立像 | 32×64 / 1×2 | [[0,0]] |

RGBA透過。接続・反復不要。可視最下辺は接地セル下辺、横中央合わせ。画像高から判定を作らない。立像上部は歩行可能セルへ張り出すため既存の actor/object 共通深度順を使用する。地形・高さ・本編配置は変更しない。

制作: 小地蔵は既存画像を再利用。他2点のみ built-in image_gen で各1回制作。参照は既存小地蔵。笠地蔵の指示は「丸い石頭・合掌・赤い前掛けを保ち、広い藁笠を追加、1×1セル向け、正面浅い見下ろし、少数色ドット群、全身、背景・影・文字なし、真の透過」。立像は「同じ石肌・赤い前掛け、穏やかな顔、錫杖・宝珠・石台、1:2の細長い全身、32×64向け、下1セルのみ接地、背景・文字・後光なし」。

原画は生成結果に保持。再構築用の透過・切詰め済みsourceを `assets/settlement-editor/jizo-v1/source/` に保存。`python3 tools/prepare-jizo.py` は保存済みsourceだけでも再構築可能。最近傍縮小・24色・二値alphaで規格化する。最終PNGとmanifestは同じディレクトリ。

カタログ: `js/settlement-map/catalog.js`。実SD緋月と実レンダラーの前後合成、寸法、透過、下段のみの占有、背後への到達、衝突、JSON往復をローカル確認。`qa/jizo-preview.png` は素材比較、`qa/jizo-scene.png` は前後検査。

本編配置・Pages公開・ブラウザ操作・実機Safariは未実施。見た目承認待ちの素材候補として扱う。前回の季節樹木コミットから分岐しているため、同ブランチには季節樹木も含む。

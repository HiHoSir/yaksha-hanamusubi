# 鬼灯村：中央追従カメラとマップ外の草地

基点: main `5f5b1be97193cb6a147a76b170bc4ae94dfe5491`。作業ブランチ: `improve/hozuki-camera-grass`。

通常表示では補間中の緋月の可視中心を画面中央に置く。マップ端でカメラを固定せず、マップ全体が画面より小さい場合も同様とする。既存のフィールド基準ズームは維持する。明示的な全体表示だけは従来どおりマップ中央へ合わせる。

本編の鬼灯村レンダラーは `SMCatalog.byId.ground_grass.src` の採用済み32px草地を読み込み完了待ちに含め、画面に見えるマップ外セルだけへワールド原点にそろえて繰り返す。マップ内の原画・配置・PNG・NPC・入口・保存・通行判定は変更しない。外側の草地は表示専用で、マップ外は引き続き通行不可。

検査: 新規2検査は修正前に失敗を確認した。四隅・南入口・歩行補間・縦横画面サイズで中心座標を確認。実タイルとの画素比較で外側の草地を確認。既存の本編フィールド往復、里長イベント、宿の出入り、保存往復、NPC原本ハッシュ、歩行、カメラ補間、保存互換、物語、ビルド整合の関連15検査PASS。独立村ビューの描画・操作・全セル到達など12検査もPASS。実game.jsの南入口キャンバスをレンダリングし、中央の緋月とマップ外の草地を目視確認した。

GitHub登録・Pages公開・ブラウザ・iPhone Safari実機は別工程。ローカル検査をPages・実機の合格として扱わない。main統合時にはAGENTS.mdのBETA/cache/runtime build同期規則に従う。

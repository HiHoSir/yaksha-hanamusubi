# 旧版基盤の段階的近代化（第1段階）

## 決定
- 開発基盤はこのリポジトリを使用する。
- フィールドと鬼灯の里の既存描画（奥行き・霞・水・高低差・カメラ・遮蔽）を保護する。
- 新生版の緋月描画・歩行・ジェスチャーは今後、独立したアダプターで接続する。
- 画像や音声のROM抽出物を新規に持ち込まない。

## 今回の変更
- `qa/architecture-guard.cjs` に構造上の基本契約を追加。
- CIに上記チェックを組み込み、毎回実行する。
- ゲーム本体、CSS、画像、セーブ、入力、描画結果は変更しない。

## 次の段階
1. 現行PagesのiPhone Safari目視スクリーンショットを基準化。
2. ゲーム状態、イベント、戦闘、描画の依存を小さく分離する（既存API互換）。
3. マップ寸法とキャラクター表示規格を、旧セーブ互換を保ちながら可変化。
4. 新生版の緋月描画を差し替え可能なアダプターとして接続。
5. 段階ごとに村・フィールド・戦闘・セーブ・iPhone Safariを回帰検査。

## 注意
構造検査は視覚的一致やiPhone Safari動作を保証しない。画面変更が意図的な場合のみ、実機確認後に基準を改訂する。

# 鬼灯村の中央出入口修正 — BETA 16.1.34

症状: area=village、tile=(10,17)、pixel=(336,560)、facing=d から南へ戻れない。

原因は二つ。添付データの出口markerが(9,17)/(11,17)だけで、出現点の中央セル(10,17)が出口に含まれていなかった。また最後の行から南へ進む入力は、出口処理の前にマップ外移動として停止していた。

`hozuki-village-game.js` で中央セル(10,17)を明示したランタイム出口へ追加した。元の配置・判定JSON・地面画像・背景画像は保持する。`game.js` は出口セルでの南向き入力をマップ外の移動検査より先に処理する。入場直後の向きは北のままで、入場しただけでは退出しない。既存の左右出口や通常の歩行・衝突は維持する。

修正前に失敗する2検査を追加し、修正後にPASSを確認。中心と既存左右セルの出口判定、内側の行・マップ外の非出口、入場後の待機、南入力による本編の退出、接触セル外の安全なフィールド復帰を検査した。村の往復・会話・宿・保存・NPC原本・中央カメラ・草地・移動・ビルド同期を含む関連17検査PASS。公開後のiPhone Safariは別の確認工程とする。

# 里マップエディタ：手動歩行判定（sm-7）

2026-10-24。画像の配置とは独立して、マップ全体のセルに通行可・不可を指定できる。

## 初期値

- 建物：入口を置く下段と、その1マス上の計2段を明示した初期占有とする。上段は建物幅の全セルを通行不可。下段は入口の中央セルを除き通行不可。絵の上端やPNGのアルファから判定を算出しない。画像・接地位置・セルサイズは変えない。
- 既定の入口セルは建物マスクから除外し、入口markerの移動時も新セルを関連建物マスクから除外する。利用者は「物体の占有」で入口を再び塞ぐこともできる。他物体や手動不可が同じセルにあれば、その判定は残す。接近セルに加え入口そのものへ一歩入れる。
- 畑は `occupiedTiles: []`、通行可。井戸、木、小物、川などの既存初期値は維持。
- 自動橋は引き続き下にある自動川だけの通行不可を解除する。

## 手動指定の優先順位

「自動＋手動修正」は素材の判定から始め、手動の通行不可・通行可を最後に適用する。「通行可」は建物・小物・川も含めて上書き可能。「手動判定を解除」は指定を消し、素材の初期判定に戻す。描画範囲や占有データは書き換えない。

「完全手動」は素材・橋・入口の初期判定を使わず、手動で塗ったセルだけを使う。未指定セルは通行可。切替時に既存の手動指定は維持する。画像の追加・移動・削除でも手動指定はマップの同じセルに残る。

通常のブラシは同じセルの可・不可を互いに除去して矛盾を防ぐ。旧データで両リストに同じセルがある場合は明示通行可を優先する。

方式切替、手動ブラシともUndo/Redo・保存・JSON往復に対応。歩行判定ブラシを選んで塗ると判定色表示を自動で有効にする。到達検査・試し歩き・判定JSONは同じ最終判定を使う。

## 保存互換

編集JSONはversion=2を維持、catalogRevision=4、collisionMode=auto/manual。旧version1→旧カタログ→新歩行規則の順に移行する。旧建物・畑の占有が旧既定値と完全一致する場合だけ更新。ユーザーが物体占有を編集済みの場合はそのリストを保持する。入口は既存の店中央移行以外は動かさない。

既存配置で新しい建物上段が他物体の占有と重なる場合、そのセルは他物体に既に占有されているので、新規建物マスクには重複登録しない。二重占有の検証失敗で保存を失わない。旧データはauto方式として読み込む。

本編・旧室内エディタ・ゲームセーブは変更しない。これは独立した改善エディタの規約。

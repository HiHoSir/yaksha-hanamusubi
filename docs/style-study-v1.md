# ヒヅキ基準の里長・地蔵：画風確認候補

ユーザーが指摘した既存NPCの太い輪郭・大きな色面と、ヒヅキの細かい陰影の差を比較する。今回は正面静止の里長1人と新地蔵1体だけを、ユーザー指定で1回の生成にまとめた。旧地蔵は参照にもベースにも使っていない。NPC全員や4方向の一括刷新はまだしない。

主参照は `assets/characters/hizuki/field-sd-v1/walk-atlas-32.png`。里長の `assets/characters/new-npc/chief.png` は人物の外見・服色だけの参照。生成指示の要点：ヒヅキの細い色付き輪郭、SD2頭身、細やかなコンパクトな陰影を両者へ統一。里長は禿頭・白髪白髭・緑の着物、地蔵は灰色の石・赤い前掛け・合掌・低い台座。二つの独立した正面全身を等高で横に並べた真の透過シート。文字・背景・床・外部影なし。最終28pxで目・髭・手が読めるようにする。

単独32×32 RGBA、可視高28pxをセル中央。NPC候補と地蔵の外見のみの比較なので、ランタイム・当たり判定・配置・セーブは変更しない。将来の地蔵接地は占有[[0,0]]で独立登録し、フィールド案内地蔵の既存通行ルールは別途維持する。

生成原画は生成結果に保存済み。分離済みsourceを同ディレクトリに保存し、`python3 tools/build-style-study.py` で比較PNGと32px候補を再構築する。2点とも同じ処理で28px化し、強制12色減色や黒い顔パッチで上書きしていない。表示用拡大は最近傍。

検査図 `qa/style-study-v1.png` は上段等倍、下段4倍。寸法とRGBA・二値alpha・セル内収容は確認。画風と読みやすさは承認待ち。特に地蔵の石肌の細かい陰影は実寸で引き続き評価する。原画の見栄えをゲーム完成品質の証拠にしない。本編置換、Pages、実機検査は未実施。

# 天妖の社：原画の切り抜きレイヤー（BETA 16.1.18）

原画WebPは保存し、`python scripts/split-tenyo-layers.py`（Pillow）で1536×1024 RGBA PNGを4枚生成する。リサイズ・移動・描き足しはしない。PNGの透明部分も含め、各分割の選択領域は元画像のRGBA値をそのまま保持する。

|画像|切り分け|描画位置|
|---|---|---|
|torii-base|元画像のy=608以上（接地行19以降）|背景の上、すべての木々より下|
|torii-upper|元画像のy=608未満|人物と同じ足元の奥行き順|
|trees-back|原画y<224の北側の森、および社のalpha>0のシルエット内にある木々|社・人物の下|
|trees-front|上記以外の手前側の木々|人物・鳥居上部より上|

IMG_6683.jpegの地面模様を元マップと照合し、緋月の立ち位置をcolumn 14,row 6（world 348,156）付近と特定した。該当マスの下端は原画y=224。上側7行の木々をtrees-backへ移し、この木の幹が頭を覆う問題を修正する。北側の森は人物より下、南側の森は人物より上。

社は人物より下。鳥居上部の奥行き基準は既定の接地行20の手前端（world y=504）。移動中の人物の描画足元で比較する。画像マスクは描画専用で、通行判定には使用しない。48×32のユーザー指定JSON、32pxの元画像セルと24 world単位の対応、カメラ倍率、既存座標は維持。

全パーツは同一原点で描く。最近傍サンプリングで分割境界を一致させ、半端なカメラ座標でも隙間・二重描画を防ぐ。`qa/tenyo-layers.cjs` は北側の立ち位置・境界を含む全人物と手前木々の前後関係、`qa/tenyo-cutouts.cjs` は実画像alphaの排他分割、北側の頭位置で人物が木の幹より前になること・南側では人物が枝葉に隠れることと5種類のカメラ位置での再合成を検査する。WebPのYUV復号はPillowとnative canvasで微差があるため、RGBAの厳密保持は分割スクリプト内、カメラでの再合成はPNGから復元した同じ画素を基準に検査する。

CIの既存Playwright 1.51.1がUbuntu 26.04で起動できなかったため、実行OSをubuntu-24.04へ固定。ブラウザ試験の省略や判定緩和はしない。

エリア移動は分割画像6枚の読み込み完了を待つ。読込イベントは本編の再描画へ接続し、保存データから社へ復帰した際も入力なしで表示が更新される。画像失敗時は移動を取り消す。既に社にいる場合は残りの画像と人物を表示し、再読込メッセージを出す。

この版は改善ブランチで確認する。Pages公開およびiPhone Safariの実機表示確認は、ソース／native canvas検査とは別に実施する。

確認ページも本編の社と同じ58pxの見かけの高さ・足元オフセットで採用済み青髪256pxアトラスを描く。本編の人物描画と縮尺は変更しない。native QAも本編のhero/shadow関数をそのまま使用する。

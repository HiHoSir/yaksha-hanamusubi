# 鬼灯の里：トップビュー素材・歩行検査 v1

本編未統合の改善ブランチ `improve/hozuki-topview`。基準mainは `b081348abdfe8b0744eaef614dc612acb4bee8e1`。実機Safari操作検査と美術の最終承認は未実施。

## 再構成

- 48列×40行、1セル32px、1536×1280 world pxの正投影。生成された1374×1145pxの全景をそのままゲーム背景には使わない。
- 8棟、6本の独立樹木、3畑、井戸、2橋、高台・坂、南北出口を持つ里専用の配置。ユーザー指示により旧配置の厳密な再現は不要とし、通路とセル内表示を優先して再配置した。元の本編データは変更しない。
- 建物・畑・井戸は背景として合成。樹冠が通行セルに張り出す6本の樹木だけ、緋月の補間中の可視足元と並べ替える。建物に汎用の前景切り抜きは行わない。
- フィールド用タイルは使わない。草・川・橋・崖・滝・境界の森を含む今回生成した里専用地面画像を、正投影の1536×1280空間に描画する。画像を32pxタイルとして切り回したり、反復させたりしない。衝突・坂の接続は別の明示セルデータ。画像アルファ・物体の幅・影から占有を算出しない。
- 畑は宣言した長方形の床装飾枠を満たす形で描画し、余白だけのセルを通行不可にしない。他の物体は縦横比を保って枠内に収める。
- 新規RGBAアトラス9種は独立生成。等分3×3にならなかったため、実際の余白を確認したsourceRectsを記録。ソース矩形は表示専用で、occupiedTilesには使わない。実行時のアルファ補修はない。
- 緋月の既存SDアトラスを変更せず使用。方向ごとの全3フレームの可視アルファunion（alpha>=32）で中央配置し、可視寸法28px以内かつ元32px枠もセル内に収める。素材のalpha=1の透明余白も削除しない。全12フレームの実描画アルファがセル外へ出ないことを検査。

## 移動

`js/hozuki-topview-rules.js`の明示したoccupiedTilesが、歩行・経路探索・配置の共通データ。画像の幅、高さ、影、アルファからセルを算出しない。4方向・32pxの一歩を開始前に検査し、144msでセル中心間を補間する。橋は欄干セルを閉じ、床だけ開ける。坂は辺の両端と中央の高さを照合し、途中の横入りを禁止。高台80、社の階段32の高さ情報は地面素材とは別に保持する。

マップタップ、十字キー長押し、キーボード、行き先選択、配置検査、グリッド／通行不可／中心・足元表示、全景／追従表示に対応。会話・室内遷移・セーブ・NPCは本検査版には接続していない。localStorageは使用しない。

## ローカル検査

- `node qa/hozuki-topview.cjs`：占有セルの整数・範囲・重複、14地点への経路、2橋、4方向、壁・橋欄干、坂の上下接続と横入り禁止。
- `node qa/hozuki-topview-motion.cjs`：一歩の原子的開始、補間、連続入力、タップ経路、途中の追加入力、通行不可セルへの移動拒否。
- `node qa/hozuki-topview-render.cjs`（@napi-rs/canvas）：1536×1280描画、9素材の実RGBA・sourceRect、18物体の描画範囲、緋月全12フレームのセル内収容、木の前後描画順。clean/grid PNGを出力。
- JS構文検査、検査ページの相対パスを確認。ネイティブCanvasとロジック検査を、ブラウザやSafariの操作検査の代用として報告しない。

美術の統一感・草と森の反復・橋と段差の仕上がりは、公開した検査版で確認する。これは素材化と移動を検査する候補であり、本編の全イベント互換性や最終美術の合格を宣言するものではない。

## 実機確認前の状態

ローカル経路・描画検査は合格。実ブラウザの初期化、タップ・長押し、地面画像と通行境界の端の目視、樹冠下での見やすさ、Safariでの操作感は公開後の検査対象。生成画像の原寸は1374×1145、アトラスは1254×1254であり、生成時点で32px完成チップだったとは扱わない。素材は専用背景と独立RGBA物体として利用する。

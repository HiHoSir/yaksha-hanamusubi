# 祠・鐘撞堂・神社を独立素材として保持する

2026-10-24。現行の祠は画像・ID・占有・入口・配置を変更せず保持する。鐘撞堂と神社を別のIDで追加し、旧祠から自動置換しない。

新規2棟は独立した建物スプライト。横3×高さ2マス、96×64px、正投影トップビュー、真正RGBA透過。村の既存ピクセル画を画風参照にする。原画は新規生成が必要（既存の祠を分解せず、鐘や社殿の意匠を別に描く）。32pxの移動セル基準に整形し、接地左端は最下段左端。

- 鐘撞堂：木の四柱と和風屋根、大きな青銅の梵鐘を中央に吊り、撞木がある開放的な建物。参道・境内・外の付属物は含めない。
- 神社：朱色の柱、木と白壁の小さな社殿、しめ縄と紙垂、中央の出入口。鳥居や境内一式は含めない。

初期占有は上段3セル＋下段左右2セル。下段中央は出入口・調査位置として通行可、接近セルはその1マス手前。デフォルト5セルの占有を直接指定し、画像のalphaから判定を作らない。自動＋手動修正・完全手動は既存通り使用できる。

原画、規格化PNG、実SD緋月との比較、衝突と入口経路、保存往復、GitHubの実バイナリ、Pages、Safariを別段階で検証する。本編や既存保存を変更しない。

## 実装記録
新IDは building_belltower と building_jinja。PNGは assets/settlement-editor/religious-v1/ に保存し、各96×64、32色以内、硬いalpha、下辺接地。原画のパス・プロンプトは generation.json。内蔵image_genで2点の原画を制作し、prepare-religious-buildings.pyで規格化。原画がない環境でも保存済みPNGを使える。

左から旧祠・鐘撞堂・神社を並べ、実SD緋月を接近セルに置いた比較は qa/religious-buildings-preview.png。これは素材検査図。68件PASS、追加テストは実装前REDを確認。旧祠のSHA-256不変、58素材の寸法、RGBA、5セル占有、中央入口と接近セル、手動通行可、JSON往復を検査。Pages・Safariは別途。

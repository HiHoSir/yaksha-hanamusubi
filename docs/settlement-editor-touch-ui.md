# スマホ操作（sm-4）

2026-10-24。ユーザー指定「スマホでも操作しやすく」「プルダウンは使いにくい」「UAによって切り替えてもいい」に対応。

## 操作

- 操作モードを「配置操作／歩行判定／出入口」の分類ボタンと、各操作の直接ボタンへ変更。
- 配置操作は置く・選ぶ・移動・複製・画面移動。移動／複製時に物体が未選択なら、まず物体を選び、その後に配置先をタップする。
- 倍率は縮小・現在倍率（押すと100%）・拡大・全体表示のボタン。入口・出口は名称と座標を表示した選択ボタン。
- ネイティブselectは既存コントローラーの値保持用として非表示にし、画面上の操作はすべてボタンで行う。値・changeイベントは従来の編集処理へ渡す。
- 素材を選ぶと配置モードへ戻り、スマホの素材パネルは閉じる。選択中の物体名・現在の操作説明を地図の近くに表示する。

## スマホ画面

- 横幅900px以下またはcoarseポインタでタッチ向けの配置を使用。UA変更・iPadのデスクトップ表示でも画面と入力能力に追従するため、UA文字列だけの判定には依存しない。
- 地図を中央に残し、画面下の「素材／選択中／保存・設定／歩行」から各パネルを開く。閉じるボタン・背景タップで閉じられる。
- 原則44px以上のタップ領域。方向ボタンは56px。素材一覧は3列で縦スクロールし、保存設定は16px入力文字でiOSのフォーカス拡大を避ける。
- safe-area-inset-bottomとsvhを使い、ホームインジケータやSafariバーを考慮する。地図の画面移動モード、縮尺ボタンを使って編集対象へ近づける。
- ボタン・素材・キャンバスの長押し文字選択や吹き出しを抑える。説明文などの通常テキストは選択可能。
- 広いマウス画面では従来の左右パネルを維持し、操作ボタンは共通で使う。

# 室内素材の村画風照合・調整 v2

対象は improve/interior-map-editor-32px の室内エディタ。main本編は変更しない。

## 検査結果と修正
- 壁・柱：元の平坦な色面と、村の木枠の質感が不一致。採用済みトップビュー茶店の梁と側柱、村の民家の窓より上の漆喰を加工して再構成した。壁は32px、側壁は上辺8pxの回転、左はx24..31、右はx0..7を維持。
- 板床：点状ノイズが強かったため、採用茶店中央通路の板床を再利用。土間は元画像から12色へ整理。どちらも上下左右の境界を整えた。
- 階段：登録済み画像が矩形の仮描画で上書きされ、パレットとも違っていた。既存の階段画像を整理し、登録画像をパレットとマップで共有するよう修正。1マス階段は低い床の上端から21px内に描く。
- 卓・座布団・茶器：仮描画から採用茶店の実画像へ移行。明示したシルエットで切り抜き、従来の32px配置と通行可否を維持。
- 棚：縮小で潰れた商品を村の壺と籠へ置換。3パーツの継ぎ目を保ち、色味を茶店の木材へ整理。
- 新規画像生成なし。元アトラスと家具v1はそのまま残す。

## 操作と方針
- `index.html` → 設定の「主人公の歩行画像」に「新・花結びの歩行（80×112原画）」を追加。
- `?heroArt=hana` または設定欄の「新」を選択。既存の `sd`, `pixel`, `bluebob`, `legacy` に戻せる。
- 初回／未設定は新歩行版。設定選択は `localStorage["yaksha_hana_walk_variant_v1"]`（ゲーム本編セーブ領域とは別）とURLに反映。
- 32px移動格子、1セルの通行判定、移動速度・マップサイズ・保存状態は**変えない**。見た目と衝突を分離する。

## 実装する描画経路
1. **フィールドと天妖の社ほか**：`js/game.js` の共通 `hero()` から新アトラスを呼ぶ。
2. **鬼灯村**：`js/hozuki-village-game.js` の既存ソート済みプレイヤー位置に新アトラスを描画。足元の奥行き基準は旧SDと同一。
3. **室内マップ**：`js/interior-maps.js` の旧SD専用描画箇所へ新アトラス分岐を追加。接地位置は旧セル画像の最下端 `view.y+16`。
4. 新画像がまだロードできない場合は既存のSD描画へフォールバック。元素材は削除しない。

## 採用歩行サイクル（2026-11-08 ユーザー確認）

比較プレビューで「足揃えあり」が自然と評価されたため、新緋月 `hana` の**実際の探索歩行でも採用**する。
一歩分の移動時間を変えず、各32px移動で次の表示を繰り返す：

- 奇数歩：歩行Aを移動の前半60%、足揃え（直立）を後半40%
- 偶数歩：歩行Bを移動の前半60%、足揃え（直立）を後半40%
- 停止時：直立（従来どおり）

見た目は `A → 足揃え → B → 足揃え` の繰り返し。歩幅（32px）、移動時間、向き、当たり判定、セーブ形式、歩数カウントは変更しない。
`js/hizuki-hana-walk.js` の純粋関数 `frameAt(stride, elapsed, duration, feetTogether)` を、
`js/game.js` の `fieldMotion` 更新とプレビューの両方で使用する。
`fieldMotion` を使うフィールド・鬼灯村・室内・社の歩行時に同じ描画状態を用い、旧SD等は従来の `[1,0,1,2]` を維持する。

プレビューには比較用として `足揃えなし` のA↔Bも残すが、新緋月のゲーム内採用値は「足揃えあり」。画像アセットの各画素・行列配置は一切変更しない。

QA: `qa/hizuki-hana-walk.cjs` で複数の移動時間に対し60%境界の前後とゲーム組込みパスを検証し、
`qa/hizuki-hana-walk-preview.cjs` で切替比較時の実描画・黄色枠を検証。

## エリア別の表示切替（2026-11-08）

ユーザー方針：「村の中は新グラフィック、フィールドはSDでもよい。ひとまず切替可能にする」。

`js/game.js` の歩行画像選択を、エリアごとに**独立した設定**へ分離。
- フィールド、フィールド検査：初期値 `sd`。従来選択肢 `hana/sd/pixel/bluebob/legacy` を保持。
- 鬼灯村、室内（茶店・宿・民家など）、天妖の社とその他探索マップ：初期値 `hana`。比較用に `sd` へ切替可能。
- 設定UI：`fieldHeroArtSelect`（フィールド）、`heroArtSelect`（村・室内・社）。
- 保存先：`yaksha_hana_walk_field_variant_v1`、`yaksha_hana_walk_settlement_variant_v1` の2つの独立したlocalStorageキー。
- URL：`?fieldHeroArt=sd&settlementHeroArt=hana` など。以前の `?heroArt=hana` を明示したリンクは従来どおり両方へ適用できるよう維持。
- 旧localStorage `yaksha_hana_walk_variant_v1` と、セーブデータ本体は書き換えない。
- 描画経路で `currentHizukiArt(S.area)` を呼び出すため、マップ遷移時に設定が自動反映される。
- 新画像には承認済み A → 足揃え → B → 足揃え の60/40%タイミング、SDには既存の歩行タイミングをそのまま適用。
- 原画、足元アンカー、32px移動格子、速度、当たり判定、敵／戦闘画像は変更しない。

追加検査：`qa/hizuki-walk-area-preferences.cjs` は実ゲームから抽出した設定コードをVMで実行し、
フィールドSD・村／室内／社Hanaの初期値、独立切替、再読込、URL、旧テストリンク、セーブ非干渉を検証。
`qa/approved-walk-runtime.cjs` のSD専用VMにはエリア別選択関数のスタブを追加し、旧画像の描画検査を維持。

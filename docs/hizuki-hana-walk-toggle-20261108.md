# 鬼哭の花結び：緋月の歩行アセット切替（改善ブランチ）

2026-11-08 更新。これは**歩行グラフィック**の実装であり、戦闘画像 PR #40 とは別件。

## 画像正本
- 承認済み原画：`assets/characters/hizuki/hana-20261107/walk/walk-atlas-80x112.png`
- アトラス：240×448 RGBA／1フレーム80×112／4行（前・後・右・左）×3列（待機・一歩目・二歩目）
- 足元アンカー：フレーム内 x=40, alpha下端 y=105。描画の底面を y=106 (exclusive) にする。
- 読み込み・縮小：`js/hizuki-hana-walk.js` を全探索シーンで再利用し、nearest-neighborで可視高約48pxへ縮小する（原画のファイル自体は変更しない）。

## 操作と方針
- `index.html` → 設定の「主人公の歩行画像」に「新・花結びの歩行（80×112原画）」を追加。
- `?heroArt=hana` または設定欄の「新」を選択。既存の `sd`, `pixel`, `bluebob`, `legacy` に戻せる。
- 初回／未設定は新歩行版。設定選択は `localStorage["yaksha_hana_walk_variant_v1"]`（ゲーム本編セーブ領域とは別）とURLに反映。
- 32px移動格子、1セルの通行判定、移動速度・マップサイズ・保存状態は**変えない**。見た目と衝突を分離する。

## 実装する描画経路
1. **フィールドと天妖の社ほか**：`js/game.js` の共通 `hero()` から新アトラスを呼ぶ。
2. **鬼灯村**：`js/hozuki-village-game.js` の既存ソート済みプレイヤー位置に新アトラスを描画。足元の奥行き基準は旧SDと同一。
3. **室内マップ**：`js/interior-maps.js` の旧SD専用描画箇所へ新アトラス分岐を追加。接地位置は旧セル画像の最下端 `view.y+16`。
4. 新画像がまだロードできない場合は既存のSD描画へフォールバック。元素材は削除しない。

- 改善ブランチを本編として正式公開／mainマージしたとは扱わない。Actions成功、Pages成功、iPhone Safari目視確認を個別に報告する。

## 注意
この検証は歩行グラフィックの読み込みと足元の正しさが中心。絵柄／NPCとの大きさの最終採用は、実機の村・室内・フィールドを歩かせた結果で判断する。

## 採用歩行サイクル（2026-11-08 ユーザー確認）

比較プレビューで「足揃えあり」が自然と評価されたため、新緋月 `hana` の**実際の探索歩行でも採用**する。
一歩分の移動時間を変えず、各32px移動で次の表示を繰り返す：

- 奇数歩：歩行Aを移動の前半60%、足揃え（直立）を後半40%
- 偶数歩：歩行Bを移動の前半60%、足揃え（直立）を後半40%
- 停止時：直立（従来どおり）

見た目は `A → 足揃え → B → 足揃え` の繰り返し。歩幅（32px）、移動時間、向き、当たり判定、セーブ形式、歩数カウントは変更しない。
`js/hizuki-hana-walk.js` の純粋関数 `frameAt(stride, elapsed, duration, feetTogether)` を、
`js/game.js` の `fieldMotion` 更新とプレビューの両方で使用する。
`fieldMotion` を使うフィールド・鬼灯村・室内・社の歩行時に同じ描画状態を用い、旧SD等は従来の `[1,0,1,2]` を維持する。

プレビューには比較用として `足揃えなし` のA↔Bも残すが、新緋月のゲーム内採用値は「足揃えあり」。画像アセットの各画素・行列配置は一切変更しない。

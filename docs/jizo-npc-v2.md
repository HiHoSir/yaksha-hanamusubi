# 地蔵 v2：NPCサイズへの置換

旧地蔵・前回不採用チップを原画、形、色のベースに使用していない。新原画は実NPCと井戸の画風のみを参照して1回生成。独立オブジェクト、正面の浅い見下ろし、丸頭・合掌・赤い前掛け・簡単な石台。少数色と大きいドット群で32px向けに設計。

PNGは32×32、可視範囲は20×28px。実SD緋月・村NPCの可視高さ28pxと比較した。透過、下辺接地、地面との接続不要。元の24×40画像を `assets/terrain/places-v1/jizo.png` で置換し、loader寸法・キャッシュquery・全宣言表示枠を32×32へ更新。各配置の横中央とfootは維持。フィールド案内地蔵の contactTiles、occupiedTiles=[]、walkThrough=true、案内会話を維持。村パーツは独立ID jizo_small、占有[[0,0]]。

原画は生成結果に保持。再構築用sourceは assets/terrain/places-v2/source/jizo-new.png。旧PNGは再構築に一切使用しない。前回不採用の jizo-v1 ブランチは統合しない。

qa/jizo-npc-scale.png は実キャラ比較。ローカル寸法・alpha・構文・案内ヒント検査済み。GitHub登録、Pages、実機Safariは個別に確認する。

## 最終画素の修正と今後の制作
目は最終32px上で左右同形の4×2pxの閉じ目、口は4×2pxの微笑、合掌は縦の2本の手と中央の溝として修正。`tools/fix-jizo-features.cjs` は新原画由来の32px sourceから再構築し、以後縮小しない。比較図の上段は等倍、下段は最近傍4倍。NPCの目形状修正版と同様、寸法合格だけでなく顔の形を最終画素で検査する。

ユーザー指定：同系統の人型チップはNPCのデザイン方式を使い、種類・占有・最終サイズを生成前にまとめる。生成が必要な複数チップは1回の分離可能な素材シートにまとめて生成回数を節約する。旧地蔵をベース・参照にしない。今回の修正では追加生成なし。

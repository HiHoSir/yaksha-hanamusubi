## 遷移・保存

フィールドは既存の明示接触セルへ重なり、歩行完了後に暗転する。新村の配置・判定・地面・物体・12NPC・SD緋月の読込を待ってから状態を確定する。失敗時は既存の遷移エラー処理でフィールドに留まる。

南の2出口でフィールドへ戻る。保存した侵入地点から到達可能で、村の接触セル外にある安全なセルを選ぶため、戻った直後の再侵入を避ける。フィールドの位置・進行フラグは別データとして維持。

宿・店・茶屋・民家3棟は旧lastInterior IDと既存屋内へ接続。退出は新マップの同じ入口の接近セルへ戻す。旧室内セーブで対応建物がない場合も村の出現点へ安全に戻る。

旧villageセーブで `hozukiVillageRevision` がない場合だけ新村出現点(336,560)へ移し、quest・装備・所持金・訪問履歴を保持する。新村の有効な保存座標は保持する。save.jsの保存キーと移行コードは変更しない。

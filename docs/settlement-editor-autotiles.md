# 村用の畑・オートタイル・縦横の橋（sm-5）

更新：sm-6で新規配置の橋は1セルの自動接続へ変更。旧2セル橋は保存互換用に保持する。現行仕様と再構築手順は [1マス橋規約](settlement-editor-bridge-autotiles.md) を参照。

2026-10-24。ユーザー指定の「畑を二列、1マス全体」「川・道のオートタイル」「橋を縦横」に対応する。フィールド用の既存タイルは流用しない。

## 素材

- 畑: 32×32pxを土で全面充填。緑の作物は横3株×2列、計6株。接地占有は従来どおり1マス。複数マスへなぞって配置可能。
- 草地: 村用の32×32全面タイル。道・川の外周も同じ草地画素を使い、隣接する草地と接続する。
- 道・川: 上下左右4方向と斜め4方向を見るblob方式、各47パターン。32pxセル、8列×6行の256×192pxアトラス。最後の1セルは未使用・透明。中心・直線・端・外角・内角・分岐・十字・広い面に対応する。
- 川の幅は1セルの中心部で24px以上。地形の見た目と歩行セルは別であり、川セル全体を明示占有として通行不可にする。
- 木橋: 横64×32px＝2×1セル、縦32×64px＝1×2セル。同じ平面の橋桁を90度回転して材質と大きさを統一。地面レイヤーに描き、緋月を隠さない。
- 元の小さい畑・橋・地形断片は原本として残す。旧道・川・草地の断片IDは読み込み互換用に保持し、素材パレットから隠す。旧川断片を勝手に新オートタイルへ変換しない。

## 制作とデータ

内蔵画像制作で村の承認背景を画風・配色の参照に、畑・土・水・草地・平面木橋の5素材を制作した。畑は二列の全体、土・水・草地は平面の素材面だけを生成。接続の形を画像生成の精度任せにはしない。

`tools/build-village-autotiles.cjs` がsource PNGを32px規格へnearestで整え、色数を抑え、繰り返す素材面の対辺を一致させる。47形状は `js/settlement-map/autotile.js` の共通ルールで組み立てる。生成原本は会話の生成画像として保持し、再構築に必要な規格化source PNGをリポジトリに保存する。

出力先: `assets/settlement-editor/terrain-v1/`。`road-47.png`、`river-47.png`、各preview、5 source、`bridge-h.png`、`bridge-v.png`、`manifest.json`。ソースから再構築する場合は `node tools/build-village-autotiles.cjs`。Nodeと@napi-rs/canvasが必要。

接続ビット: N=1、E=2、S=4、W=8、NE=16、SE=32、SW=64、NW=128。斜めビットは両隣の直交ビットが有効な場合のみ採用。正規化した47マスクを数値昇順に並べ、`manifest.json` と実行モジュールで同じインデックスを使用する。

画像制作の制約:

- 畑: 土が正方形の端まであり、上から見た三株×二列。余白、木枠、ラベル、立体プランターなし。
- 土: 薄い黄土の踏み固めた土だけ。草・道形状・影・枠なし。
- 水: 明るい青の水面と短い波だけ。岸・岩・滝・方向依存の流れなし。
- 草: 黄緑系の低い村の草地だけ。木・花・岩・大きい茂みなし。
- 橋: 平面の横2×縦1セルの木橋桁。余計な背景、背の高い欄干、地面の影なし。外側は真正RGBA透過。

## 配置・判定

- タップ式操作に「地形」分類を追加。道・川・草地・地形消しを直接選ぶ。素材パレットの新道・川・草地・畑もなぞって配置できる。
- 同じ地形を同じマスへ重複追加しない。道と川は同じsurface枠を置き換える。草地は別の下地枠。地形消しは新しく塗る地形だけを消し、建物や旧地形断片を消さない。
- 速い指移動の間のセルを4方向で補間して塗り、1ストロークを1回のUndo/Redoとする。
- 川のoccupiedTilesは整数の1セルを明示。PNGの色・アルファや47形状から衝突を推測しない。
- 橋の通行セルは横 `[[0,0],[1,0]]`、縦 `[[0,-1],[0,0]]` を接地座標へ加算して明示する。その場所の**自動川**だけを通行可能にする。手動の通行不可や他物体の占有は維持する。
- 橋を移動・削除すれば、下の川の通行不可が自動で戻る。見えない壁や古いpassageを残さない。既存の手動terrainPassagesは明示的な地形通行設定として維持する。
- 判定JSONは同じ最終占有から書き出す。編集JSONでは素材IDとセル座標を保持し、接続形状は読み込み・描画時に再計算する。セルサイズ16〜64pxでも同じデータを使う。
- 新素材を含む28テンプレートを読み込む。マップを全面に塗ることに備えてオブジェクト上限を20,000件とする。JSON 8MB、PNG面積、マス数などの上限は維持する。

## 検査

50件PASS。従来の40件に、マスク47種、素材反復辺、畑の全面アルファと6株・二列、隣接画素、重複と置換、縦横橋、橋の移動削除、川・手動壁・建物判定、JSON往復、高速ストロークとUndoを追加。

道・川それぞれについて1,024の横接続と1,024の縦接続（合計4,096組）を組み、共有辺の全RGBA画素が一致することを検査した。ネイティブの組み立て例は `qa/village-terrain-preview.png`。これは接続と素材の検査図であり、完成した村の配置ではない。

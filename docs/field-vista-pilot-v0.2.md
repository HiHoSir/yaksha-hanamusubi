# 冒険風景パイロット v0.2 — 時期混在を解消するための美術基準

## 改修理由

初版 v0.1 は製作時期と用途が異なる次の素材を混ぜていたため、実寸と見た目が噛み合わなかった。これはユーザーが2026-11-07に指摘した重要な不適合。

- `field-map-objects-v3`: 村・木・山・神社など、縮約したフィールド/ワールドマップ記号（例えば村64×32、木32×32）
- `terrain/places-v1`: 鳥居64×64、地蔵32×32
- `terrain/landscape-v2`: 石灯籠24×40、橋96×40
- `animation/fluid-v1`: 別規格の滝（160×96アニメシート）
- `settlements/common-v1`: 探索用の細密な花素材
- `field-sd-v2`: 実際の本編で使用する最新採用緋月 `field-sd-v3` より古い

**同じ32pxグリッドに置ける＝同じ世界観の画面を組み立てられる、ではない。** 特にワールドマップ用の縮約アイコンをSD緋月と同じ歩行スケールの建物・木として使わない。

## v0.2 の固定範囲

対象: 歩行できる「村外れの花道」。これは**美術検証のための小画面**であり、新規マップの採用や本編改修ではない。

- 主人公: 本編表示と同じ `assets/characters/hizuki/field-sd-v3/walk-atlas-32.png`、96×128の4方向×3コマ
- 地面: 本編の草原基材 `assets/terrain/grass-v1/grass.png` のみ（256×256の32pxセル反復）
- **全独立オブジェクトを同一素材セット** `assets/settlements/common-v1/` から選ぶ
- 木（原画192×158）、民家（256×175）、岩（112×67）、井戸（80×98）、畑（160×95）、柵（128×72）
- 地面の花: 同じ `common-v1/wildflowers-4x4.png` の32pxセル（接地判定なし）
- フィールド縮約アイコン、別世代の鳥居・社・橋・滝は不使用
- 視点: 正投影トップビュー、論理マス32px、4方向のセル移動
- 建物・樹冠の表示サイズと整数の `occupiedTiles` は完全に分離。PNG矩形から通行判定は算出しない
- 家の出入口(15,8)、接近セル(15,9)は歩行可能
- 木の占有は幹の各1セルだけ。木冠の画像は前後描画を許す
- 新規の画像生成／PNG編集／本編ファイル変更はなし

## 根拠と寸法

`js/settlement.js` は同じ `common-v1` 素材を描画しており、木の表示幅おおむね136〜180ワールドpx、建物は192〜256ワールドpxを採用している。今回の局所マップは木を132〜148px、民家を192px、岩を72〜80px、井戸を64pxに設定し、表示比率を明示した。

この単一セットで「美しいか」は**実画像表示で別途審査する**。単に同じパスに揃えたことを画風統一の合格とは判定しない。

# 32pxの面積を活用する画風候補 v2

ユーザー指定により横幅を活用する構造へ変更。里長は広い袖・短い胴・開いた足、地蔵は幅広い頭・短い胴・台座を使う。単にv1を横へ引き伸ばしてはいない。ヒヅキの画風、里長の人物像だけを参照し、里長と新地蔵を1回の透過シート生成にまとめた。旧地蔵はベース・参照に使用していない。

生成指示：二つの正面独立全身、共通基準32×32、幅27〜28・高28〜29のほぼ正方形シルエット、幅広いSD頭と短い胴、ヒヅキの細い輪郭・繊細な色分け、里長は白髪白髭と緑着物、地蔵は灰石・赤前掛け・合掌・低台座。背景・文字・グリッド・床・影・余分なポーズなし。原画の生成成功を最終寸法の保証とはしない。

最終実測：里長28×30px、地蔵26×30px（各32×32 RGBA、二値alpha）。里長は縦横比保持で縮小。地蔵原画はまだ縦長だったため、幅26pxの一様倍率で33px高へ規格化した上で、額4行目・下部衣26行目・台座31行目の繰返し3行を除去して30pxに再構成した。目・口・合掌の行は除去していない。横方向への非等方拡大なし。

`python3 tools/build-style-study-v2.py` で保存sourceから再構築する。`qa/style-study-v2.png` はヒヅキ、v1里長、v2里長、v1地蔵、v2地蔵の順。上段は等倍、下段は4倍。枠は32pxセルを表す。比較値は可視alpha>=128で統一。

分類：正面静止画の画風候補のみ。今回ユーザー指定の30px高は旧28px上限からの限定的な比較変更。本編採用前に歩行余白・4方向・キャラ接地・物体の占有と深度順を個別設計する。配置・衝突・セーブ・ランタイムは未変更。完成品や採用済み画像とは扱わず、PagesとSafari検査も未実施。

# 室内素材の見直し

2026-10-25、改善ブランチ `improve/interior-map-editor-32px`。以前のムシロの市松模様、単純な囲炉裏、過度な縮小、座布団に長椅子を流用した誤りを修正する。新しい見た目は確認用の候補であり、全体の美術品質が承認済みという意味ではない。

## 方針と変更

- 家具や装飾を1マス／2マスへ一律に収める制約を撤廃。今回は既存の部屋寸法を維持したが、今後は固定の部屋寸法より絵と動線を優先する。32pxの移動グリッド、明示する整数占有、左右の壁を全行へ通す配置は維持。
- 畳んだ布団は5施設の配置から除外し、旧素材をパレットで非表示にした。古い保存データとの互換のため元画像とIDは残す。
- ムシロは新しい一枚の絵を320×192のキャンバスに縦横比を保って収める。繊維、束ねる糸、縁、わずかな擦れを描き、単純な市松模様をやめた。木床を下に敷いて透過した縁を処理し、60個の32px床片へ同じ座標で分割。一枚として同時配置でき、占有は空・高床として通行可。
- 囲炉裏は木目、灰、炭、薪を描き直し、四隅に出ていた柱状の部分も修正。その後、追加指示に従い、少し手前から見下ろす横長の角度に変更。手前の木枠と灰床のくぼみを見せる。96×64の一式、明示占有3×2。消火版と点火2コマ版を用意。火以外の木枠と灰床はコマ間で固定。
- 座布団は藍色の四角い布として新規制作。長椅子の切り抜きを使わない。32pxは人が座る大きさとして選んだ値であり、素材全体への上限ではない。
- 座卓は採用茶店の原画を64×64へ、武器掛けは96×32へ配置し、元絵の細部を残す。鎧は壁際に32×64で描き、床接地1セル・上の壁への重ねとして登録。床に張り出す上半分は作らない。
- 畳も描いた繊維から素材を再構成し、市松状の反復を除去。従来の畳IDのまま画像を差し替える。
- ムシロ・囲炉裏・座布団は組み替えだけで補えなかったため画像生成を使用。囲炉裏は枠と視点を狙った編集を2回実施。他の絵は採用済み原画を加工。実寸の室内と緋月を合成して確認した。

## 保存・再構築

`assets/interior-editor/quality-v1/source/` に再構築用の原画チェックポイントと全プロンプトを保存。生成時の大きな原画は生成履歴に残す。

`python3 tools/build-interior-quality.py` → `python3 tools/build-interior-examples.py` → `node qa/interior-completion.cjs`。

旧ムシロ・旧囲炉裏・旧卓などは保存互換を維持し、パレットでは非表示。既存のユーザー配置を勝手に大きな素材へ移行しない。今回の配置例は新素材を使って更新した。

# 原作世界図：東側の細い接続候補と原寸照合 v4.3

## 手法と前提
- 内部ROM復元画像 `world_map_4096.png`、4096×4096pxを使用し、1024×1024の海4色マスクへ正規化。
- 非海マスクに2回の二値侵食を実施。侵食によって失われた非海画素の近傍に、侵食後の**異なる**成分ラベルが存在する領域を「細い接続候補」とする。
- 候補を少し拡張して集約し、東半分（比較座標x>=500）の領域を優先して、上位候補の原寸450×390px画像を目視確認。
- **検出した候補は橋の確定位置ではない**。山の間・川幅・海岸先端・小島などでも候補となる。候補領域の大きさ（score）は橋の長さや面積ではない。
- ROM由来の切り出し画像 `rom_east_necks_v43_internal.png` は内部検査専用で、公開用アセットには使わない。

## 今回の判断
1. 東側の連結は**単一の自然地峡**として単純化できない。北東と南東の途中には水路・細い島・複数の橋が含まれる。
2. 縮小色マスクでつながっている箇所に橋が混じるため、非海マスクの連結成分をそのまま地理上の自然陸塊数として採用しない。
3. 今回の試験で、東側の切断候補を比較画像座標と原寸画像座標に対応させた。ただし、接続種類の全件確定と橋の地理イベントIDの特定は未完了。
4. **外形を合格にするための次工程**は、確認した橋チップの個所を内部地形マスクからだけ除外し、自然地形による連結グラフを再計算すること。単純な円形除外では橋の周辺まで削るため使用しない。
5. 地図画像の再生成は行わない。ROM画像・輪郭データを公開GitHubへ転載しない。既存の `js/world.js`、新大陸80×80、旧セーブ互換を変更しない。

## 合否
- **PASS**：原寸で複数の橋および複合水路を確認。主要な候補座標を整理。
- **PENDING**：橋のタイル画素だけを除外した自然陸塊の連結性と、世界全図の外形検査。
- **FAIL**：現行水彩地図の外形を完成版として採用すること。

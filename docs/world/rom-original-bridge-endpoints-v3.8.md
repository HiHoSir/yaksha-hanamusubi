# 原作世界地図：橋の両岸と水路構造の原寸再検証 v3.8

## 手順
ROM解析で復元した4096×4096画像の次の中心を、それぞれ760×760pxの原寸範囲で切り出して目視検査した。下記は位置同定用の原作画像内部座標であり、公開用地形画像への転写データではない。

## 判定結果
| 原寸検査中心 | 観察結果 | 外形設計への反映 |
|---|---|---|
| 西側 (792,2028) | 上部の緑・黄の岸と下側の緑の岸の間は海面。確認した範囲内の最短接近箇所に橋は視認できない | この箇所の海峡を埋めない。西側の全海域に橋がないとは断定しない |
| 東側北部 (3512,1320) | 上方の大きな陸地から南の細長い陸地へ短い橋が架かる。東のさらに細い陸地側にも別の橋がある。橋の間は海面で分離 | 地表の連続した海岸線と橋接続を分離。海峡を保持 |
| 東側南部 (2904,2184) | 島状の陸地と多数の水路が交錯し、いくつもの短い橋がある。陸地同士を直接埋めてはいけない | 水路を保持し、橋位置は外形確定後に別レイヤーで定義 |

## 前段階の解釈の補正
- v3.6での「東側南部に橋あり」は、複数の橋があることを再確認。単一の橋で陸地同士をつないでいるわけではない。
- v3.7での「西側の別の接近地点に橋がある」という記述を、西側検査中心 (792,2028) の事実と混同しない。今回確認した西側原寸範囲内では橋を視認していない。
- 大陸全体の連結性（西側南北の別経路を含む）はまだ確定していない。
- 非海マスクの連結性だけでは、陸続きか橋接続かを区別できない。

## 判定
- PASS（局所）: 西側検査地点の海分離、東側北部の橋２か所、東側南部の複数の水路と橋。
- PENDING: 原作地図全域の陸地連結判定。各橋の原作内部イベントIDと地名との対応。公開用オリジナル海岸線の最終合格。
- 再生成は行わない。ROM画像・画素マスク・抽出輪郭を公開GitHubに置かない。原作からは地理構造を参考にし、公開用グラフィックは独自制作。
- `js/world.js` の80×80新大陸、既存クエスト、旧セーブ互換は維持する。

# 世界地図 島の位置・サイズ・重なり検査 v3.4

## 比較対象
- 内部資料: ROM復元地図 `world_map_4096.png`、4096×4096。
- 比較画像: `水彩幻想地図_七つの国々.png`、1254×1254。
- 双方を1024×1024へ正規化。対象島の局所窓内で色分類し、最大8近傍連結成分の外接矩形・重心・面積・未位置補正IoUを測定。
- **重要**: ROM由来の画像・輪郭マスクは非公開の内部検査用。公開ゲームへのコピー・直接輪郭トレースは行わない。

### 水彩版／ROMの相対サイズ
- 鬼ヶ島: 横幅 1.345倍、縦幅 1.082倍。中心差 (水彩−ROM) = (-0.5,-7.1)。
- 竹の島: 横幅 0.715倍、縦幅 0.745倍。中心差 (水彩−ROM) = (-37.6,+7.0)。
- 補正方針: 鬼ヶ島は横方向の過大さを抑える。竹の島は相対的に東へ移し、横・縦とも拡大。正しい周辺小島関係は別途判定。

## 判定の限界
- 数値は「同一座標窓内の色分類マスク同士の未補正IoU」であり、真の海岸線・島の完全一致率ではない。
- 文字・縁飾り・水彩の海辺のハイライト・地形装飾がマスクに混入し得る。特に竹の島は複数島の接触判定が不確実。
- 公開用の海岸線をROMのピクセルから写し取るのではなく、**地域の位置・大きさ・付属島の相対関係**を制約として独自に描く。
- 検査票は途中段階。西側・東側の外接範囲と接続グラフ、新大陸の適地は引き続き未合格。

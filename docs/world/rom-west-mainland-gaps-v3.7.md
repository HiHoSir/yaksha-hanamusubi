# 原作世界地図・西側の陸地間隔と局所橋の検査 v3.7

## 検査条件
- 内部検証用 `world_map_4096.png` (4096×4096) を最近傍1024×1024に縮小し、海候補RGB4色を除いて4近傍連結成分に分解。
- 最大の非海領域 (307820px, bbox 31,87,973,918) と南西の大領域 (51060px, bbox 67,511,317,978) の最短距離を計算。
- 検出された候補を4096px画像で原寸切り出しして目視。内部用画像 `west_gap_v37_internal.png` は公開ゲーム・GitHubに載せない。
- **非海は通行可能な陸地とは限らず、橋や描画オブジェクトも含まれる**。

## 結果
- 最短の２領域間距離: **6.0比較px（原寸で約24px）**。
- 最近点: 北側 (196,505)、南側 (196,511) ※1024比較座標。原寸の目安 (784,2020)〜(784,2044)。
- 原寸目視：この近接地点の間に**海面がある**。したがってここを自然な陸続きと扱わない。
- 別候補: 北側 (323,604)、南側 (316,603) の約7.07比較px。原寸目視では近傍に**橋の描画が存在する**。ただしこの橋が上記２大成分を直接つなぐものとは断定しない。接続する両岸は別途追跡する。
- 南部（南西成分 y≥700）の最接近は約51.79比較pxで、北部付近より離れている。

## 採用できる修正条件
1. 西側北部と南西部の最近接海峡を勝手に地峡として塗りつぶさない。
2. 橋の存在と島・大陸の地形連続性を切り分ける。橋がある地点を海岸線の連結点として扱わない。
3. 「西側北部・南西部のどこにも接続経路がない」とまでは判断しない。全通路判定は保留。
4. 今は原作海岸線の直接トレースや水彩画像の再生成を行わず、検査事項だけ固定。
5. 既存新大陸80×80、`js/world.js`、旧セーブデータは変更しない。

## 続く検査
- 原寸画像で橋の両岸を追い、どの成分をつなぐかを分類する。
- 東側の細い連結地点について同様に局所検証する。
- 地理接続を分類した後、外形デザインの修正に進む。

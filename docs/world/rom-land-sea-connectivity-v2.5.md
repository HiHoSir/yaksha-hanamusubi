# 新・桃太郎伝説 ROM世界地図：海陸分類の実測 v2.5

## 入力と処理
- 入力：内部検証用 `world_map_4096.png`（4096×4096、ROM解析資料）。
- 処理：1024×1024へ最近傍縮小し、海に多い三つのRGB値 `(24,115,123)` / `(16,90,98)` / `(32,139,148)` を海として分類。
- 3×3ピクセルのクロージング後、海以外を8近傍で連結成分解析。
- 複製画像、ROM由来の海岸線ベクトル、座標を公開ゲームに流用しない。本ファイルは検証方法と暫定統計だけを記録する。

## 初回結果（1024px検証座標）
- 海として分類：63.78%。
- 面積100px以上の非海領域：13件。
- 最大成分：305,626px、外接矩形 (31,87) 幅941×高さ830、重心 (561.4,413.2)。
- 第二成分：50,623px、外接矩形 (67,511) 幅249×高さ466、重心 (187.8,719.1)。
- 第三成分：16,634px、外接矩形 (419,659) 幅185×高さ164、重心 (514.6,747.8)。
- 第四成分：2,837px、外接矩形 (483,467) 幅57×高さ60、重心 (511.1,500.5)。
- 複数の海岸線らしき境界と水路を確認。ただし「海以外＝陸地」の誤分類、幅1pxの接続、細い海峡は今後要検査。

## 重要な修正
- 第2～第5章の「単一大陸」「西・東の二大陸」いずれも、最終確定事項として扱わない。
- 初回の分類では西側から東側へ延びる一つの巨大な非海連結成分がある。この判定は原作ゲームで地表移動可能であることを意味しない。
- 内部では原作地図の海陸分類を利用するが、公開作品の地形輪郭は参照情報を元にオリジナルで制作する。
- 鬼ヶ島の同定、新大陸の追加座標、旅立ちの村の正確な位置は引き続き未確定。

## 次の検査
1. 海色の全パレットを洗い出し、非海に分類された浅瀬・川・湖を分離する。
2. 大成分の細い接続と橋・地峡を局所確認する。
3. 島・半島・湾の接続グラフを作成し、原作地名を後から対応付ける。
4. 公開用の輪郭を独自にデザインし、既存の新大陸80×80・旧セーブを維持する。

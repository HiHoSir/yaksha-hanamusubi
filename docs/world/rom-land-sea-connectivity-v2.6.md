# ROM世界地図 海陸連結の再検証 v2.6

## 検証条件
- 内部ROM解析画像 `world_map_4096.png` (4096×4096 RGB) を、最近傍法で1024×1024に縮小。
- 出現色49色。海候補色を従来の3色に加えて `(8,65,74)` も含む4色で再分類。
- 海4色: `(16,90,98)`, `(24,115,123)`, `(32,139,148)`, `(8,65,74)`。
- 4近傍（上下左右）、8近傍（斜めも含む）、8近傍＋1px opening の各条件で非海領域をラベリング。
- **注**：海以外と判定されたピクセルには、浅瀬、橋、建造物、川、地形装飾等も含まれる可能性がある。通行可能な陸地との同一視は禁止。

## 比較結果（1024px画像上）

海4色・8近傍の最大3成分の外接矩形（x, y, 幅, 高さ）:
- 最大: (31, 87, 942, 831)
- 2番目: (67, 511, 250, 467)
- 3番目: (419, 659, 186, 165)

## 結論
1. 主要な非海領域の面積と成分数は、海候補3→4色、4→8近傍、1px opening によって大幅には変化しなかった。
2. ただし、最大の成分が「原作で自由に行き来できる一つの大陸」であることは未証明。橋・装飾等が細い接続を作ることや、海色以外の水地形を含む誤分類は残る。
3. 西・東を地表上の別大陸と断定したv2.4の結論も、一枚の巨大本土と断定した初期案も撤回し、**原作の地形属性・局所通路で検証する**。
4. 原作データは内部照合に限り、公開用の海岸線・マップチップはオリジナルで制作する。
5. `js/world.js`、新大陸80×80、旧セーブおよび既存進行には変更なし。

## 次の検証
1. 49色パレットとメタタイルの対応を取り、海・湖・川・歩ける浅瀬・装飾を区別。
2. 最大成分内の細い結合部分の座標を特定し、ROM地図の該当箇所と突き合わせる。
3. 原作地名と確定した陸地の成分を紐付ける。ただし公開ゲームにはROM画像・タイル・正確な海岸線をコピーしない。

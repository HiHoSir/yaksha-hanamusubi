## 判定
- PASS: 両画像の正方形キャンバス。主要地域の名称と大まかな方角。
- FAIL: 海岸線の形・大きさ・位置の検査。**生成水彩版は外形設計の正式採用をしない。**
- PENDING: 旅立ちの村の座標と追加新大陸の最終位置。
- WARNING: 検出値は色分類条件に依存するため、正確な輪郭一致率（IoU）として扱わない。比較窓の境界でクリップしたbboxを大陸全体のbboxとして扱わない。

## 修正する場合の優先手順（勝手に画像生成しない）
1. 原作の海陸マスクを小地域ごとに精度確認し、島と大陸の連結を判定する。
2. 対象の陸塊ごとに、正方形キャンバス内の中心・相対幅・面積を固定。
3. 既存水彩版で変化した位置と島の大きさを具体的に修正。
4. 再度マスク測定と目視確認をしてからグラフィック採用判断を行う。
5. ROM地図画像・マスク・原寸輪郭は公開GitHubへアップロードしない。公開用は独自制作の地形を使う。
6. `js/world.js`（新大陸80×80）、既存セーブ・進行は変更しない。

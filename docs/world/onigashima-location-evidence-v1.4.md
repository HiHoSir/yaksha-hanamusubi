# 鬼ヶ島・勇気の岬の原作地理照合 v1.4

## 確認できた相対位置
- 『新・桃太郎伝説』攻略チャートによると、勇気の岬は「すゞめのお宿７」の北西にある。
- 勇気の岬の入口には地蔵が2体並んでいる。
- 地蔵の間で勇気の剣を使うと海が割れ、鬼ヶ島への道が開く。
- この情報は原作ゲーム内の相対関係であり、正確なマップ座標・鬼ヶ島輪郭を保証しない。

資料:
- https://onibaka.donburako.com/kouryaku/momo_shin/chart_6.html
- https://w.atwiki.jp/retrogamewiki/pages/10286.html

## デバッグ画面への反映
- `debug/world-overview-v14.html` に「すゞめのお宿7(仮)」「勇気の岬」と二体の地蔵をオリジナル描画で表示。
- 岬と鬼ヶ島を結ぶ海割りルートは、解放イベントを示す模式線として維持。
- 鬼ヶ島は愛と勇気の国の北側に仮置きしたまま。原作の絶対位置は未確定と明示。
- ROM由来の画像・タイル・海岸線トレースは公開資料に含めない。

## 重要な保留事項
1. 手元の4096px ROM解析画像に対して、勇気の岬・すゞめのお宿7・鬼ヶ島を個別に同定する。
2. ROM解析画像に出てくる鬼の顔のような地形を、鬼ヶ島と断定しない。
3. 地形配置は原作の相対関係を参考にしつつ、公開用の陸地は必ずオリジナル制作する。
4. `js/world.js`、現行セーブ、既存の新大陸を変更しない。

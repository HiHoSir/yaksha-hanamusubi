# 鬼ヶ島地理照合 v1.5（ROM画像の識別結果）

## 分かったこと
- ROM復元世界地図 `world_map_4096.png` を1024pxに縮小して点検した際、ほぼ中央、縮小座標およそ (510,500) に鬼の顔のような独立した島がある。
- 原画像に換算した観察用の概算座標は約 (2040,2000)。正確な地形境界・イベント座標ではない。
- 攻略記事でも「鬼の顔の形をした鬼ヶ島」が言及されている。これと地形の特徴が一致するため、この地形を **鬼ヶ島の有力候補** と判断する。ただし画像単独で内部地名IDを証明したわけではない。
- 『新・桃太郎伝説』では、すゞめのお宿7の北西に勇気の岬があり、地蔵2体の間で勇気の剣を使う。海が割れて鬼ヶ島へ渡れる。
- 別の解説でも、竹取の島の北側の岬から海を割って鬼ヶ島に行く描写がある。

## 独自世界図への設計反映
- 鬼ヶ島を愛と勇気の国の北側、勇気の岬を挟んだ海上に置く。
- 顔に見える島であることを **独自の輪郭と抽象化した表情** で表現する（ROM画像・輪郭・座標値は公開版素材にコピーしない）。
- デバッグ版は `debug/world-overview-v15.html`。ここでの座標は1120×920のオリジナル模式図専用。
- 現行の `js/world.js`、既存の新大陸80×80、旧セーブ、クエストには変更を加えない。

## 未検証
ROM側の地名IDと地形の1対1照合、岬のゲーム内精密座標、GitHub Pagesの公開設定、iPhone Safari実機動作。

# 原作世界地図との照合・修正仕様書 v3.1

## 検査対象と判定
- **基準**: 内部検証用ROM復元世界地図 `world_map_4096.png`（4096×4096）。
- **比較**: 直近の水彩生成画像 `水彩幻想地図_七つの国々.png`（1254×1254）。
- 両者は **1:1の正方形**。寸法比の問題は解消。ただし**地形の一致判定はNG**。
- 本資料は**画像の再生成指示ではなく、先にズレを固定する検査票**。これ以降の修正は各項目を検査してから着手する。
- 公開作品にROM由来画像・タイル・輪郭の直接トレースを混入させない。地理的な位置と接続関係を参考に、公開用は独自の地形を制作する。

## 修正工程の固定ルール
1. **原作地図の地理照合が先**。4096px原寸を基準とし、縮小画像だけで海峡・地峡を判定しない。
2. 位置と大きさの照合は四隅・中心のランドマーク、および各陸塊の外接範囲と面積比を使う。海岸線を公開用データとして抽出・コピーしない。
3. 地名アンカーと陸塊／島IDの対応、接続/分離の判定を記録し、未判定は空欄でなく「未検証」にする。
4. **C02・C03・C04・C05を先に合格**させ、C06（新大陸）は旅立ちの村の位置確認後に確定する。
5. **検査を通さず画像を再生成しない**。外形と位置の検査完了後にのみ公開用アートを作る。
6. `js/world.js` の既存新大陸80×80、7地点ID、旧セーブ移行は維持する。

## 現段階の結果
- **PASS**: キャンバスの縦横比1:1、6地域の大まかな方角。
- **FAIL**: 原作準拠の海岸線・地峡・島配置が一致することの確認。
- **PENDING**: 旅立ちの村の精密座標、新大陸の位置、小島の系統的対応付け。
- **結論**: 直近画像は仮の雰囲気案であり、外形確定版・ゲーム組込用アセットとしては採用しない。

# 世界地図・正方形座標での定量検査 v3.2

## 検査条件
- ROM原作: 4096×4096 `world_map_4096.png`（**内部資料**）。
- 最新比較対象として扱う画像: 1254×1254 `水彩幻想地図_七つの国々.png`（ユーザーに提示した生成版）。
- 両画像を1024×1024の比較用座標へ正規化。
- ROMは海として既知のRGB 4色を除き、生成版はHSVの青・シアン域を除いた非海領域を集計。
- 海・陸の分類には装飾、文字、縁飾り、海の濃淡などの誤検出があり得る。**以下は地形の一致率でも実際の陸地面積比でもない。**
- 公開用ゲームにROM由来画像・ピクセル輪郭を転載しない。調査数値のみを記録。

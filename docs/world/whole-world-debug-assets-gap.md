- `debug-world.html` に、独立した256×256マスの試歩行デバッグページを追加。画面周辺のタイルのみ描画（64Miピクセルの全体背景を作らない）。
- 既存アセット（草原・水・雪・砂・荒地・山など）の画像ファイルを読み込む。画像が見つからない場合は単色で代替。
- 8方向のキーボード操作、タッチ十字キー、船/徒歩切り替え、256×256ミニ地図、簡易カメラ追従を搭載。
- 全体世界の新大陸を数マスの代表島として配置し、切替時は **既存80×80データをデバッグページ内で読む**。本編のイベント・セーブへの書込みはなし。
- 地理は公開ゲーム用の**独自設計の概略地形**。検証用ZIPのROM由来分類値や輪郭をGitHubに投入していない。256×256分類の正確な地理再現版ではない。
- 現時点では **本編ゲームのフィールド切替は未実装**。ブラウザで別ページとして試歩行するための暫定環境。
- iPhone実機での動作確認は未実施。ページを実際に開いてタッチと描画を確認する必要がある。

## 地形ルール
水際の灰色部分が「水面からの高さを描くための側面チップ」の場合、地形分類上は水域として扱う。ただし山・岩の灰色は変更しない。解析データへ適用する際は誤判定防止の追加識別が必要。

## 本実装に必要な次のゲート
1. ROM解析CSVの内部検証結果を、独立制作した256×256オリジナル地形データへ翻案する。原作の画像・タイル・輪郭の直接流用禁止。
2. オートタイルと既存地形アセットの適切なマッピングを完成。
3. 港・橋・陸路、船出イベント・帰還地点を決定。
4. `js/world-map-registry.js` を本編から使用できるよう接続し、既存セーブを新大陸として読み替える。
5. iPhone Safariの起動/移動/ページ切替/描画負荷/旧セーブの回帰検査。

本編 `index.html`、`js/world.js`、`js/game.js`、`js/save.js` は今回変更しない。

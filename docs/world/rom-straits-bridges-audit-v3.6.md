# 原作世界図：橋・海峡の原寸確認 v3.6

## 検査方法
- 内部ROM解析画像 `world_map_4096.png` (4096×4096)。
- 1024px縮小した4色海マスクへ5×5侵食を実施し、分裂した主要な非海領域間の接近点を抽出。
- 候補点を原寸座標×4へ戻し、各地点を約500×500pxで切り出して目視確認。
- **注意：最近接点は必ずしも実際の橋の中央座標ではない。下記の座標は検証目印であり、ゲーム用の確定座標ではない。**

## 原寸目視の結果
| 検証候補（4096pxの概算座標） | 画面内で見えたもの | 地理上の判定 |
|---|---|---|
| 北側 `(2284,536)` | 雪原の左右岸を渡す短い橋（橋チップが見える） | **橋あり**。海峡を陸地で埋めない |
| 東側北部 `(3512,1320)` | 緑地の二つの岸をつなぐ橋（橋チップが見える） | **橋あり**。岸の自然陸続きとは分ける |
| 東側南部 `(2904,2184)` | 分岐する水路と複数の橋（橋チップが見える） | **橋あり**。水路を保持する |
| 西側南北 `(792,2028)` | 岸と岸の間に海面。中心付近に橋は見えない | **この候補点は海で分離**。周辺に別の接続がある可能性は残す |

原寸画像は内部検査のみ。ROM由来の画像、橋チップ、正確な海岸線の画素形状を公開ゲームに組み込まない。

## 再設計で守るべきこと
1. 本土の外形確認において、橋の画素連結を「陸地そのものが連続している」と誤認しない。
2. 原作の海峡・水路の有無を基準に、公開用は独自に形を描く。
3. 「西側南北の陸地は完全に分離」とは、この１検査点からは断定しない。他の候補も調べる。
4. 愛と勇気の国・鬼ヶ島は確認済みの地理アンカーのまま維持。
5. 旅立ちの村の東方沖に置く新大陸は、原作地理の把握後に追加。既存80×80ローカルマップと旧セーブには触れない。

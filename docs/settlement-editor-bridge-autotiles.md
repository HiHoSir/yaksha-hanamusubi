# 村用1マス橋オートタイル（sm-6）

2026-10-24。既存の縦横2マス橋に代わり、1×1セルで塗る橋を追加する。対象は独立した里マップエディタの改善ブランチのみ。

## 素材契約

- 種類：通行可能な地面タイル。32×32px、正投影トップビュー。既存の承認済み `terrain-v1/bridge-source.png` の木板・低い欄干の画素を再構成し、新しい原画は生成しない。
- 描画は接地マス下辺に合わせた正確な1セル。セル外への張り出しなし。デッキ外は真のRGBA透過、アルファは0/255のみ。地面レイヤーで川より上、キャラより下に描く。
- `auto_bridge` の `occupiedTiles: []`、`bridgePassages: [[0,0]]`。橋が存在する1マスの自動川だけを通行可能にする。手動壁や他の物体の占有を解除しない。
- 8列×3行、256×96pxの `bridge-17.png`。0〜15はN=1/E=2/S=4/W=8の接続ビット、16は単独の縦橋。未使用7セルは透明。プレビューは別の32×32px PNG。

## 接続

- 同じ橋の上下左右の隣接だけを見る。斜め接続はしない。直線、端、角、T、十字に対応する。
- 端の1接続と直線は軸の両端を開け、岸へ降りられる見た目にする。単独時は左右の川セル数が上下より多ければ縦橋、その他は横橋。幅の広い水面など同数の場合は横を既定とし、隣に橋を描けば連続配置が優先される。
- 接続は描画とPNG出力のたびに再計算。保存データには素材IDとセル座標だけを保持する。川の後置き・橋の移動・削除でも更新される。
- 直交接続のある共有辺の画素は全組み合わせで一致する。色は元の木材画像から採り、接続形状だけを規則で組む。

## 操作・互換

- 「地形」に「橋」「橋消し」を追加。橋はなぞって連続配置。1ストローク1回のUndo/Redo。橋は川や道とは別の描画枠にあり、下地を消さない。
- 「橋消し」は新1マス橋だけ消す。川を残し、そのセルの通行不可が即座に戻る。「地形消し」は従来どおり新しい塗り地形全体を対象にする。
- 旧 `bridge`（2×1）と `bridge_vertical`（1×2）は保存データの互換用に読み込み、既存配置のサイズを変えない。新規素材パレットでは隠す。
- マスのpx変更16〜64にも同じ論理セルを使用。本編・旧室内エディタ・ゲームセーブは変更しない。

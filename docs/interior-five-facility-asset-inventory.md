# 室内素材一覧 — 5施設の実機参考を反映
更新：2026-10-25。対象：improve/interior-map-editor-32px。これは制作台帳であり、未制作の絵を完成扱いしない。

## 確定した読み取りと訂正
- 参考画像の順序は民家、医者、宿、茶店、武具屋。
- 医者の丸い器具は火鉢。薬壺と読み替えない。
- 茶店左下の色違いの器具はかまど。色違いを同じカテゴリの別色として制作する。
- 民家の敷物はムシロ／ゴザ系として扱う。畳に置き換えない。織り方の厳密な種類は未確定。
- 宿は畳と布団、客室の間仕切り、障子引き戸、廊下、庭のある構成。
- 囲炉裏は枠＋たき火の組み合わせ。火鉢・かまどと別ID。火の細部は大枠の後。
- 箪笥は壁付け1オブジェクト。床1セルを占有し、上半分は奥壁へ重ねる。
- 柵は高床への侵入防止に必須ではない。段差の移動制御と装飾は別。現状の柵IDはまだ通行不可なので、任意装飾化は別の実装作業として残す。

## 制作・検査方針
- 村の採用済み画風と実SDを基準とし、添付画像は物の種類・配置・組み立ての参考にする。
- 原作画素の切り抜きを公開ゲーム用素材として登録しない。
- 柵の任意装飾化は提案済み・未実装。画像生成やこの台帳の作成だけで完了と報告しない。
- まず床の敷物と布団、火鉢・かまどを揃え、その後に宿の仕切りと武具・庭を進める。
- 新しい画像はasset-designの事前契約とcreate-grid-map-artの工程に従う。再利用・加工を先に検査。
- 未確定の接地寸法・通行可否を、画像から推測して実装しない。
- 個別チップ、接続、実SDとの32px合成、接地判定、経路、GitHub実体、Pages、実機Safariを別々に確認する。

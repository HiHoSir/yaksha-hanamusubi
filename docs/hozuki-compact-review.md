# 鬼灯の里：小さめの複数マス建物・配置比較v2

ユーザーの補足：建物は規模に応じて小さめの複数マスでよい。基本オブジェクトは1マス、高さが必要なものだけ最大2マス。屋根・樹冠の裏へ潜り込む表現は避ける。旧配置の再現は不要、マップ寸法の変更可、フィールド用タイル不使用。

## 比較案

- マップを24×20セル（768×640px）へ縮小。1セルは32pxのまま。緋月を小さくして建物との比率を合わせない。
- 宿・茶店3×2、民家・店・小社2×2。建物全体を1マスのミニチュアにする案は不採用。
- 独立した木・井戸・畑は各1×1。今回は1セルに収まる樹木を再利用し、高さのための2セル化は必要になった物体だけ別途定義する。
- 物体の可視範囲を宣言したセル枠に収め、その全セルを通行不可とする。幹だけを塞いで樹冠の下を歩かせない。前景分離・足元による前後切替は使わず「地面＋全物体背景＋キャラ」で描く。物体の北側に空き床があればキャラ全体が見えたまま歩ける。
- 前案の里専用地面と独立透過アトラスを再利用。フィールド素材・旧地形チップの参照なし。縮小だけで新規の手打ちドット絵が完成したとは扱わず、現段階は実マス・実SDでの大きさと配置の比較案。

## 検査

`NODE_PATH=<canvas依存先> node qa/hozuki-compact.cjs`

1マス小物、建物2×2/3×2、18物体の占有重複なし、描画枠外への張り出しなし、13地点への経路、緋月全12フレームの実アルファが停止セル内、物体との深度切替なしを確認。768×640のclean/grid画像を出力する。

木を2セルにする場合も、両セル全体を占有にする。位置は描画寸法やアルファから推測せず、ルール側で指定する。

本編未統合。地面画像の境界の細部、橋の欄干との見た目、Safari操作は別検査。本案の画像比較を、旧イベント・会話・セーブ互換性の検査済みへ読み替えない。

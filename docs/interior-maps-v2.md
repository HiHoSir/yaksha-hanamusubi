# 5施設の室内マップ

2026-10-25。既存の生成済み家具・建具・庭素材を使って、民家・医者・宿・茶店・武具屋を歩いて確認できるようにした。新規画像生成なし。対象は `improve/interior-map-editor-32px`、本編mainへの統合は承認後。

## マップ契約

32px正投影、現行緋月SD、上下左右のセル移動。占有・階段・高床の判定は室内エディタと同じ関数を使用する。家具の一式配置、壁付け箪笥の床1セル、水と火の2コマを維持。

| 施設 | 列×行 | 構成 |
| --- | --- | --- |
| 民家 | 12×11 | 縁・四隅まで揃えたゴザの生活区画、囲炉裏、卓、壁付け箪笥、畳んだ布団、土間のかまど・薪・壺 |
| 医者 | 12×12 | 薬箪笥、帳場、火鉢、屏風、診察用布団、土間の備品 |
| 宿・庭 | 18×18 | 帳場と待合、障子・襖で分ける2客室、畳と8組の布団、廊下・階段、池・石灯籠・植栽・踏み石 |
| 茶店 | 14×13 | 左奥の高床と帳場、壁付け箪笥、土間の赤い長椅子4組、木蓋の羽釜を載せたかまど |
| 武具屋 | 14×12 | 高床の帳場、刀・槍の展示台、鎧飾り、壁掛け武具、土間の備品 |

左右壁は全施設の最上段・最下段を含む全行へ配置する。左端は左側壁、右端は右側壁とし、上・下の横壁で四隅を置き換えない。横壁は左右の内側セルから始める。初期配置と従来の高床店舗サンプルも同じ規則に修正。既存のユーザー保存配置を自動改変しない。

## 確認画面

- `interior-maps.html`：5施設の画像と「歩く」リンクをまとめた一覧。
- `interior-map-editor.html?play=1&map=home`：歩行確認。mapはhome/doctor/inn/teahouse/armory。
- 確認画面では編集パネルを隠し、施設切り替え、全体表示／100%、マス目、判定、入口リセット、近くの建具の開閉を用意した。方向ボタン・矢印キーで緋月を動かせる。ドラッグは画面移動。
- 最初は全マップが画面に入る倍率にする。読込中は古い部屋を隠し、移動を停止。必要な素材と緋月のdecode完了後に表示する。読込失敗後も別施設への切り替えを可能にする。
- 編集用とは別の保存キー `yaksha.interiorMapEditor.v1.map-preview` を使用。施設切り替えはテンプレートを読み込み、元の編集データを上書きしない。確認画面では出現点・出口の検査マーカーとキャラ枠を隠す。

配置JSONと実描画PNGは `assets/interior-editor/completion-v1/`。再構築は `python3 tools/build-interior-examples.py` と `node qa/interior-completion.cjs`。

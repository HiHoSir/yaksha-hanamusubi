対象は改善ブランチ `improve/interior-map-editor-32px`、基準コミット `882e3f6d5a8e65b4c493ced3fe473abfd4e6e4d4`。本編mainへの統合は承認後。添付された実機画像は物の役割と組み立ての参考とし、原作画素は使用していない。

## 制作契約

32px正投影。可視約28pxの現行緋月SDをセル中央に合成。家具は指定セル内で完結させ、上方へ伸びる薬箪笥だけは既存の壁付け箪笥と同じ例外を使う。足元はセル下辺、薬箪笥の上半分は通行不可の壁にのみ重ねる。その他は可視矩形外への張り出しなし。全PNGはRGBA・二値アルファ。衝突は画像ではなく明示したoccupiedTilesで決める。

| 対象 | 表示・配置単位 | 占有と配置条件 |
| --- | --- | --- |
| 障子・襖 | 64×32、2×1の一式。開／閉 | 閉は左右2セル、開は左1セルだけ通行不可。右1セルを通行可 |
| 間仕切り | 横・縦32×32、各1セル | 通行不可。縦は細い木部だがセルを明示的に塞ぐ |
| 出入口の木枠 | 32×32 | 通行可。自動接続機能ではなく独立した枠素材 |
| 屏風 | 64×32、2×1一式 | 両セル通行不可 |
| 薬箪笥 | 表示32×64、配置・接地1セル | renderRect=[0,-32,32,64]。北隣に通行不可の壁が必須 |
| 掛け軸・壁札・壁掛け武具 | 各32×32 | 壁のセルにのみ配置。装飾自体の占有は空 |
| 武器掛け | 64×32、2×1一式 | 両セル通行不可 |
| 鎧飾り | 32×32 | 1セル通行不可。今回の判断でコンパクトな形式を採用 |
| 石囲いの池 | 64×64、2×2一式 | 4セルすべて通行不可。外周の隣セルに余分な判定なし |
| 石灯籠・低木・常緑樹 | 各32×32 | 各1セル通行不可。樹種を竹とは断定しない |
| 踏み石 | 32×32 | 通行可。既存の小型素材を使用、大きな飛び石は含めない |

## 素材の出典と再構築

- 建具：村の採用民家の紙・格子と、既存箪笥の木材を再構成。単色矩形の仮素材を完成絵に使わない。
- 間仕切り：採用済み室内アトラスの壁・木部。
- 屏風・掛け軸・札：本プロジェクトの採用済み宿原画の絵柄・木枠を使用。旧パースはカメラ参照にしない。
- 薬箪笥：既存のオリジナル箪笥の引き出しを小型に再構成。
- 武器掛け・鎧飾り・池：組み替えで作れる既存絵がなかったため、それぞれ1回だけ新規生成。`source/`に再加工用チェックポイント、`source/prompts.json`にプロンプトを保存。原寸生成画像は生成履歴に残す。
- 石灯籠：`assets/terrain/landscape-v2/lantern.png`。植栽：採用村のshrub/tree_conifer。踏み石：既存pack-v1。
- 再構築：`python3 tools/build-interior-completion.py`、`python3 tools/build-interior-examples.py`。

## エディタ

建具は「壁・柱」層、家具・庭は「家具・物」層。建具と家具とも、どの表示セルを選んでも一式のアンカーへ解決し、複製・移動・消去を一括操作する。範囲外と同層の他素材との重複を拒否する。開いた建具の空きセルも選択範囲には含めるが、衝突には含めない。

「選択した建具を開閉」で障子・襖を切り替える。緋月が開口にいる間は閉じられない。建具の開閉状態は既存JSONの素材IDで保存する。

「追加素材の配置例」で宿・庭／医者／武具屋／民家／茶店を選ぶ。既存保存配置を起動時に入れ替えない。配置例読み込み前には従来同様の確認を表示する。5例はオリジナルの組み立て見本であり、参考ゲームの間取りを厳密に写したものではない。柵は追加していない。

# 高床の店を組める室内素材セット

ユーザーの参考画像を、家具の種類・連結・高床と土間の構成の資料として使用。参考画像そのものはGitHubへ登録せず、原作画素を切り抜いた素材は作らない。

- 高床・土間・階段・壁：既存の調整v2素材。
- 箪笥：新規原画1回。RGBA、32×64px。現在は壁付け箪笥1オブジェクトで配置し、描画矩形[0,-32,32,64]で上半分を奥壁へ重ねる。床のoccupiedTilesは[[0,0]]のみ。奥壁の直下に配置する。旧上下パーツは互換用に非表示とし、壁際の旧ペアは読み込み時に1セル形式へ置換。既存の1マスdrawerは小型表示として互換維持。
- 帳場：採用トップビュー茶店の帳場をRGBA切り抜き、2×1セルを左右分割。
- 赤い長椅子：同茶店の長椅子をRGBA切り抜き、2×1セルを左右分割。
- 柵：村の柵と柱の実画像を再構成。左端・連結・右端を1セル単位で登録。高床の前を塞ぎ、階段口を1セル空けられる。

各チップは32×32pxの二値アルファPNG。見た目と判定は別管理、各パーツの明示occupiedTilesは[[0,0]]。壁付け箪笥の表示だけは32×64px、床占有は[[0,0]]。帳場と長椅子は[[0,0],[1,0]]。

配置例は14×13マス。左奥の高床5×6、3台の箪笥、帳場、柵と階段、土間の長椅子4脚、薪・籠・壺。エディタ「高床の店・配置例」ボタンから読み込める。既存配置は自動置換せず、確認後のみ切り替える。

```
python3 tools/build-interior-layout-kit.py
node qa/interior-layout-kit.cjs
node qa/interior-polish.cjs
```

検査済み：画像実体・寸法・透過、素材ID、JSON往復、入口→階段→帳場手前／店員側・全長椅子の接近セルへの4方向経路、階段の双方向通行、実エディタdraw関数での合成。配置例には矩形の仮家具を使わない。

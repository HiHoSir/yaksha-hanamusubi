# 鬼灯村：添付マップの歩行実装

対象ブランチ improve/hozuki-village、main基点74234d9d038a9c0b65fdda39fd4fe2a69e5abdc8。21×18、32px、672×576。添付4ファイルはそのまま保持する。新規原画を作らない。

1. layout.jsonを既存SMModelで厳密検査し、添付collision.jsonと207不可セル・出現(10,17)・全入口を照合。171通行可セル・9入口/出口への経路を検査する。
2. 地面PNG＋既存チップをSMRenderの共通接地順で描く。元の合成画像は見た目の参照として残す。承認SD画像を可視28pxでセル中央に描き、SMWalkの4方向144ms移動・タップ経路を使う。
3. hozuki-village.htmlから新規のcore/UIを起動。スマホは大きい十字キー、長押し選択防止、タップ移動、フィールドSDの画面サイズを基準にした追従カメラ、全景切替、入口調査、任意の判定表示。ロード完了までは入力無効、失敗時は再読込を案内。ゲーム保存やエディタ保存へは書き込まない。
4. coreテストを実装前に失敗させる。全セル経路、不可セル侵入防止、動作中の停止/入力解除、座標変換、入口認識、実SD/描画の画素検査、DOM入力解除を検査する。
5. バイナリを含む新規ファイルのみをGitHubへ登録しSHA/size照合。Pages公開可能な状態を作り、公開後の操作と配信バイトを確認する。本編へは未統合、屋内・フィールド遷移と既存イベントは未接続（旧鬼灯の里と位置・イベント対応が異なり、セーブを自動変換しない）。

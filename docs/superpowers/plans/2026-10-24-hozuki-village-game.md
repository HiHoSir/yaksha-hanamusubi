# 鬼灯村を本編へ接続する

main 903f58e7032505153aff9c58e230e905ecdfd575 から improve/hozuki-village-game を作成。既存の鬼灯村配置を別モジュール YK_HOZUKI として保持し、本編の area=village の行き先をこのモジュールへ置換する。フィールドの接触セル・ワールド座標は変えない。

1. main/new-npcの対応表でID対応を固定。屋外8人は通行可能なセル中央へ配置し、各人へ隣接会話と全入口動線を確保。屋内4人は既存担当を維持してID単位でnew-npcを描く。会話・サービス・里長の物語進行を引継ぎ、旧地形に依存する案内だけ修正。
2. 添付layoutとcollisionは不変。NPC占有は別に1セル追加。移動は32pxの4方向atomic stride。新村で旧SETTLEMENTの歩行・NPC徘徊・画像描画は呼ばない。
3. 本編canvas768×768に村とSDキャラを描画し、フィールドの緋月と同じ基準倍率を維持。描画とNPC会話・占有に同じセル中心を使用。new-npcはleft=2/right=3、静止列1を守る。
4. フィールド侵入は既存の重なり→歩行完了→暗転→必要素材読込完了→新村出現。村南出口でフィールドへ戻り、接触セル直上への自動再侵入を避ける。宿/店/茶屋/家は既存内装へ接続し、退出時は新入口の接近セルへ戻す。
5. 古い村セーブ座標だけは一度新村の出現点へ安全に移し、進行・装備・訪問履歴は保持。新村保存は同じ位置を復元。屋内の旧セーブも出口で新村へ戻れる。
6. 純粋ルールのRED→GREEN、実Canvasの描画、実ゲーム起動/フィールド往復/会話・物語/屋内往復/ロード/他エリア回帰を検査。新NPC原画は変更しない。変更を改善ブランチへ登録・公開して実機確認し、承認後にmain統合。

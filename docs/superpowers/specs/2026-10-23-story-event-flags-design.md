# 物語イベントの完了フラグ

承認済み方針: マップの探索は自由とし、重要会話・報酬・次の目的だけを前提イベントで制御する。

6つの重要イベントに固定ID、前提ID、前提未達の会話、完了後の会話を持たせる。最後の行まで読み終えて初めて完了フラグを立てる。影九尾の勝利は会話完了と別に保存し、勝利後に再開しても再戦を要求しない。

`storyFlags`を正本とし、既存の`quest`は目的表示・装備条件用の連続完了数として維持する。フラグのない既存セーブは従来の`quest`までを完了済みとして移行する。報酬の再付与、既存の金銭・装備・所持品の変更はしない。

検討した方法: questだけで通常会話を分岐する方法は変更が小さいが完了理由が残らない。固定IDによるフラグ方式を採用する。マップへの立入制限は探索の自由を損なうため採用しない。

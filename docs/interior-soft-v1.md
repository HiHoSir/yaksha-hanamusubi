# 敷物と布団の候補セット

民家用のムシロ／ゴザ（中央・四辺・四隅）と宿用の畳（横左・横右・縦上・縦下）は別ID。いずれも32px、通行可能な床。通常床と高床の登録を分け、高床から敷き替えても高さ1を維持する。

布団は新規原画1回。村の採用トップビュー茶店を画風・カメラ参照に、真上寄りのクリーム色の枕と緑の掛け布団を生成。原画を二値アルファ・24色、縦横比維持で32×64へ正規化。正規化した原画はfuton-32x64.pngとして残し、上下32pxに分割。敷き布団の占有は空、畳んだ布団は実際の布地画素を折り重ねた加工候補で床1セル占有。

敷物は32pxの織り目を直接作成したテクスチャ候補。ゴザの中央タイルは四辺の反復境界を一致させ、周囲の縁は独立部品。畳は64×32の一畳を2分割し、90度回転で縦方向にも対応。色は温かな藁色と抑えた畳色で区別。

追加先：interior-map-editor.html の床／家具パレット。床の高さを素材メタデータから参照するよう統一し、階段検査、移動、編集、保存復元に同じ規則を適用。既存の板床・高床・箪笥・家具配置は維持。

再構築：python3 tools/build-interior-mats.py
検査：node qa/interior-polish.cjs と node qa/interior-layout-kit.cjs

確認済み：PNG実体、32pxと32×64px寸法、RGBA／二値アルファ、反復合成の目視、高床の敷物に対する階段の有無と双方向通行、敷き布団の通行／畳んだ布団の遮断、既存階段・壁付け箪笥・帳場経路の回帰。

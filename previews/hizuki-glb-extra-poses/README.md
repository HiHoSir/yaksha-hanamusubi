# 緋月: GLBからの追加ポーズ試作（全8方向）

- 収録: attack / magic / hurt / victory / crouch / jump、各5フレーム×8方向。
- 解像度: 256pxマスター／128px／96pxの透過PNG。寸法は画像セルの大きさであり、キャラ本体の高さではありません。
- アニメーションは既存のGLBに元から存在するものではなく、56本のボーンを操作して作成した新規ポーズを補間したものです。
- 行=方向（正面から45度刻み、時計回り）、列=時間順。
- 攻撃は武器なしの打撃です。術のエフェクト・表情変更・モーション間の滑らかな遷移は今後の調整対象。
- hand-authored pose targeting は編集可能な自動生成スクリプト `Hizuki_extra_pose_prototype.py` を参照。
- レンダリング画像の連続コマであり、ピュアなドット絵ではありません。
- ゲーム本編や既存スプライトには影響を与えません。

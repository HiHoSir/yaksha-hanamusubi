## 画面の使い方

- 方向8種、0.25〜2倍速、1〜4倍表示、通常／8→1コマ往復、コマ停止送り、残像、接地線。
- コマ1→8および8→1のα画素変化をブラウザ内でその都度算出する。相対値は見た目の自然さを保証しない。
- 元GLBの足首／つま先の前後・上下軌跡を表示（オリジナルの `Walking` / `Running`。V7ウェイトの変更による足底変形は反映していない）。
- データロード後に各アトラスの寸法を検査する。計測はブラウザの実行結果であり、現時点の静的なREADMEに未計測値を転記しない。

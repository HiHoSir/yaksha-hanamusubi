# 緋月 V7 スプライトコマ送り検査

元の Rig Repair V7 から書き出した256×256セルの透過PNGを一切リサンプルせずにブラウザの Canvas にフレーム順に描画する独立プレビューです。

- 待機：8方向×1コマ
- 歩行：8方向×8コマ、1周1.033333秒
- 走行：8方向×8コマ、1周0.633333秒
- 方向切替、再生/一時停止、1コマ送り、0.25〜2倍速、表示倍率、接地基準線、前フレーム残像
- 元の画像アセットの構造・画素数・順番を変更しない。
- スクリーンショット/再生は試作アセットの検査目的。既知の衣装干渉は未解決。

ローカルでは `index.html` を同一ディレクトリの `assets/*.png` と一緒に静的サーバーから配信すること。iPhone SafariはGitHub Pages上のURLで確認可能。

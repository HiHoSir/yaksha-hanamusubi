# 夜叉姫の花結び奇譚 β5.1

iPhone Safari / GitHub Pages 向けブラウザRPG。

## アップロード
このZIPを展開し、`index.html`、`css`、`js`、`assets` をリポジトリのルートへそのままアップロードしてください。

## β5の主な変更
- 巨大な単一HTMLを分割
- `autosave / migrate / beep / defeat` の欠落を解消
- Pointer Events中心のタッチ操作
- 十字キー長押し移動
- 戦闘コマンドを十字キー＋Aで選択
- ランダムエンカウントに最低歩数・戦闘後猶予を追加
- 7エリア実装（花霞野、鬼灯の里、天妖の社、海の入り江、忘れの森、龍神の滝、九尾の祠）
- 衣装6種を全方向表示に共通対応
- 旧 `yaksha_beta` / `yaksha_beta_auto` / 3スロットを移行
- iPhone safe-area対応

## 注意
β5は「安定したゲーム基盤」を優先した再構築版です。画像アセットはまだ外部PNG化せず、軽量なCanvas描画で統一しています。次段階でキャラクター/タイル/敵をPNGスプライトへ置き換え可能な構成です。

## β5.1
- タイトルの仮『夜』マークを夜叉姫ビジュアルへ変更
- 主人公を高密度な2〜3頭身キャラへ刷新
- 市松模様主体のマップを廃止し、建物・桜・灯籠・鳥居・橋・水面・森・滝を描き込み
- β5のセーブ/操作/戦闘基盤は維持
